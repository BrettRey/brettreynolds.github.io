CG-0015 · CGEL Ch. 5 §5.2, p. 364

Some in existential clauses

Argument gap Argument gap identifies an inference the evidence fails to establish.

CGEL’s claim

The failure of not all in the same existential frame is used to test an implicature of some.

Paraphrase of the printed text; quotation marks mark short excerpts.

Finding and limits

Syntactic substitutability is a weak test of an implicature. The distinction between proportional and non-proportional uses survives.

Evidence

There were some children in the park is natural with no larger set salient. The stronger alternative can also be negated outside that frame.

  • Audit noteChapter 5 systematic audit (working note, not published)
    CGEL passage
    §5.2, p. 364. The failure of not all in the same existential frame is used to test an implicature of some.
    Example, contrast or countermodel
    There were some children in the park can introduce an entirely new group. Where a particular class is salient, a speaker can add The rest of the class stayed at school. The stronger alternative need not occupy the postverbal NP slot.
    What it establishes
    Infelicity of not all in one existential frame gives no direct verdict on an inference about the salient class. The contrast between proportional and non-proportional uses remains.
