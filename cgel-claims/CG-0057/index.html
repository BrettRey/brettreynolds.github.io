CG-0057 · CGEL Ch. 5 §2, p. 332

Function of from Lloyds in tree [11]

Author erratum Author erratum identifies a correction by the authors.

CGEL’s claim

In the salary NP in tree [11], CGEL labels the PP from Lloyds as a complement.

Paraphrase of the printed text; quotation marks mark short excerpts.

Proposed wording

Label from Lloyds as a modifier (Mod) above PP.

Finding and limits

Change the dependent’s function label in this tree. Nothing about the correction assigns a uniform function to other from-phrases.

Evidence

Compare the printed Comp label with the authors’ published instruction to replace it with Mod. Both use PP for the category and permit the same branching.

  • Published erratumCGEL authors. The Cambridge Grammar of the English Language: Typographical and Other Errors.
    CGEL passage
    §2, p. 332, tree [11]. The PP from Lloyds, following salary, bears the function label Comp. The immediately higher relative clause has a separate attachment.
    Example, contrast or countermodel
    The authors explicitly replace the complement function label on from Lloyds with modifier. The PP category and the tree’s branching remain as printed.
    What it establishes
    An author-acknowledged change to this analysis.
    Locator
    Opening numbered list, item 1, and table entry for p. 332, tree [11].
