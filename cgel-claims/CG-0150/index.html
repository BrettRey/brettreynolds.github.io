CG-0150 · CGEL Ch. 8 §14.1.3, pp. 746–747

Only if and the entailment of only

Argument gap Argument gap identifies an inference the evidence fails to establish.

Not yet reviewed by the author. This entry was drafted with AI assistance, and its verdict may change once it has been checked.

CGEL’s claim

Page 746: “it is clear that Q only if P does not actually entail Q if P”, which is treated as an implicature. Page 747: only if “is in fact predictable from the meanings of if and only”, and “there is no need to regard only if as an idiom”, with a cross-reference to Ch. 6, §7.3.

Paraphrase of the printed text; quotation marks mark short excerpts.

Finding and limits

Medium confidence: the derivation needs a step it doesn’t give. One rescue is available in p. 747’s own analogue, whose generic prejacent (permanent residents qualify) doesn’t entail that every permanent resident qualifies, as p. 746 notes for the parallel pension example [27ii]; read the same way, Q if P would be weaker than a universal conditional. CGEL doesn’t say this. Ch. 6 n. 20 (p. 588) refers only + if to Ch. 8, which suggests the authors saw it as a special case.

Evidence

In the account cited, Ch. 6 p. 592 [62] lists “Kim resigned” as a component of Only Kim resigned, and p. 593 says “Both [ia] and [ib] entail that Kim resigned”. Built up as p. 747 proposes, Q only if P should then entail Q if P, which p. 746 denies. Page 747’s derivation covers only the excluded scenario. It doesn’t say why the positive component becomes a cancellable implicature, which p. 746 calls the “Sufficient condition implicature”.
