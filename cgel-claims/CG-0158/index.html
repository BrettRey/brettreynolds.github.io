CG-0158 · CGEL Ch. 8 §14.4, p. 757

If only and the reference to §14.1.3

Production error Production error records a misprint, a wrong cross-reference or a misnumbered example that the authors’ errata do not list.

Not yet reviewed by the author. This entry was drafted with AI assistance, and its verdict may change once it has been checked.

CGEL’s claim

Introducing [59] I’ll go with them, if only to get some exercise: “There is a use of if only distinct from that considered in §14.1.3 above”.

Paraphrase of the printed text; quotation marks mark short excerpts.

Proposed wording

There is a use of if only distinct from that considered in §14.2.1 above

Finding and limits

Medium confidence. Change §14.1.3 to §14.2.1. The defence that §14.1.3 is where an if phrase is the scopal focus of only (p. 746) fits the contrast in focus, but p. 757 contrasts two uses of the sequence if only, and p. 751 introduces that sequence.

Evidence

§14.1.3 (p. 746, “If in combination with only and even”) treats only if and even if, and doesn’t discuss the sequence if only. The wish use is in §14.2.1, p. 751, under the heading If only: “Quite distinct from only if is the construction where only occurs in the protasis indicating something like a wish”. Ch. 10, p. 945 cites “see Ch. 8, §14.2.1” for if only with a modal preterite.
