# CG-0010: Weekday as determiner

- CGEL: CGEL Ch. 5 §4, p. 357
- Verdict: Open
- URL: https://brettreynolds.ca/cgel-claims/CG-0010/

## CGEL’s claim (paraphrase)

The weekday is assigned determiner function in *Sunday morning*.

## Finding and limits

Identify a test for the weekday’s function in bare *on Sunday morning*. Locating the head settles only half the analysis.

## Evidence

Plural *Sunday mornings* establishes the head. Constructed *three Sunday mornings* admits an internal modifier reading.

- Audit note: Chapter 5 systematic audit (not online)
  - passage: §4, p. 357. The weekday is assigned determiner function in *Sunday morning*.
  - example: Adding plural *-s* to *morning* locates the head. In *three Sunday mornings*, *three* counts *mornings* and *Sunday* occurs within the material it quantifies. Compare the bare temporal use *on Sunday morning*.
  - establishes: There is evidence for a modifier use in the counted phrase. An independent test is needed to assign the weekday the determiner function in the bare phrase.
