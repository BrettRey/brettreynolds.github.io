# CG-0045: Adjective ordering preferences

- CGEL: CGEL Ch. 5 §15, p. 452
- Verdict: Supported
- URL: https://brettreynolds.ca/cgel-claims/CG-0045/

## CGEL’s claim (paraphrase)

CGEL distinguishes rigid order from labile preferences among modifiers.

## Finding and limits

A contextually reversed size/colour sequence fits the stated account.

## Evidence

A context that has already established the set of large sofas licenses *black large sofa*.

- Audit note: Chapter 5 systematic audit (not online)
  - passage: §15, p. 452. CGEL distinguishes rigid order from labile preferences among modifiers.
  - example: Suppose the large sofas are already established as a set and colour distinguishes two of them. Within that set, *black* can precede *large* in *black large sofa*. This is the sort of contextual reversal §15 anticipates.
  - establishes: A reversal in an appropriate context supports the description of a preference. It could refute only a rigid ordering rule.
