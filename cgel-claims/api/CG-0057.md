# CG-0057: Function of from Lloyds in tree [11]

- CGEL: CGEL Ch. 5 §2, p. 332
- Verdict: Author erratum
- URL: https://brettreynolds.ca/cgel-claims/CG-0057/

## CGEL’s claim (paraphrase)

In the salary NP in tree [11], CGEL labels the PP *from Lloyds* as a complement.

## Proposed wording

Label *from Lloyds* as a modifier (Mod) above PP.

## Finding and limits

Change the dependent’s function label in this tree. Nothing about the correction assigns a uniform function to other *from*-phrases.

## Evidence

Compare the printed Comp label with the authors’ published instruction to replace it with Mod. Both use PP for the category and permit the same branching.

- Published erratum: CGEL authors. The Cambridge Grammar of the English Language: Typographical and Other Errors. <https://pullum.ppls.ed.ac.uk/cgelerrata.html>
  - passage: §2, p. 332, tree [11]. The PP *from Lloyds*, following *salary*, bears the function label Comp. The immediately higher relative clause has a separate attachment.
  - example: The authors explicitly replace the complement function label on *from Lloyds* with modifier. The PP category and the tree’s branching remain as printed.
  - establishes: An author-acknowledged change to this analysis.
  - locator: Opening numbered list, item 1, and table entry for p. 332, tree [11].
