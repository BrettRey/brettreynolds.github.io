Download and data

The catalogue is kept as one data file per claim; these files are generated from them.

  • cgel-claim-catalogue.xlsx Excel workbook: a Claims sheet, an Evidence sheet and the coding guide, for sorting and filtering.
  • claims.json All claims with labels and guide.
  • claims.jsonl One claim per line.
  • llms.txt Notes for AI systems.

CGEL claim catalogue, by Brett Reynolds. Snapshot 2026-11-19 (5adc513). Page references are to the corrected printing of The Cambridge Grammar of the English Language (Huddleston and Pullum 2002) used for the audit.
