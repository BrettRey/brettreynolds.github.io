Describing a state with a word like locked

A word that looks like part of a passive verb can instead describe how something is.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In The door remained locked, the word locked tells us the state of the door. Nobody is said to have done anything. This dictionary tentatively treats locked here as an adjective, because the verb remain can select a description of a state.

Compare The door was locked by security at noon. There we can picture an event at a particular time, with someone doing the locking, so the verbal passive reading is possible. The two sentences share the same word shape, but the first describes a state and the second can describe an event.

Examples

  • The door remained locked.

Try it

Say The door remained locked, then The door was locked by security at noon. Which one sounds like something happening at a particular time?
