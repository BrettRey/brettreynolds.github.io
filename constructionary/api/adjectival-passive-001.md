# Adjectival Passive

## Meaning 1

Predicates a state or property through an adjective with passive-like morphology.

- *The door [remained locked].*: Constructed illustration.

## Related constructions

- A kind of: Subject-Oriented Ascriptive Predicative (`subject-ascriptive-001`)
- Compare: Verbal *be*-Passive (`be-passive-001`): *The door remained locked* supports an adjective analysis. *The door was locked by security at noon* permits the verbal passive analysis with an event time and a *by*-phrase.

## Sources

- Huddleston, Rodney & Geoffrey K. Pullum (2002), The Cambridge Grammar of the English Language. Cambridge: CUP, Ch. 16 §10.1.3 (discusses; bears on projection)

## Projection

*Remain* can select the stative predicate. A verbal passive with an agent and an explicitly dated event gives an event reading rather than the state interpretation illustrated here.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Describing a state with a word like *locked*

A word that looks like part of a passive verb can instead describe how something is.

In *The door remained locked*, the word *locked* tells us the state of the door. Nobody is said to have done anything. This dictionary tentatively treats *locked* here as an adjective, because the verb *remain* can select a description of a state.

Compare *The door was locked by security at noon*. There we can picture an event at a particular time, with someone doing the locking, so the verbal passive reading is possible. The two sentences share the same word shape, but the first describes a state and the second can describe an event.

### Teacher

Helps students tell a state described by an adjective (*remained locked*) from a verbal passive event (*was locked by security*).

In the adjectival passive, a past-participle form heads an adjective phrase after *be*, *seem* or *remain*, and the clause ascribes a state or property to the subject. *Remain* supports the adjective analysis because it can select the stative predicate. A verbal passive with an agent and an explicitly dated event, such as *The door was locked by security at noon*, permits the verbal analysis and gives an event reading instead. This dictionary treats the adjectival passive as a specialization of the subject-ascriptive pattern and marks the analysis as provisional.

### Child

Is "*locked*" something a person does, or how the door is?

In *The door remained locked*, *locked* tells us how the door is. It doesn't say who locked it. In *The door was locked by security at noon*, we hear about something that happened.
