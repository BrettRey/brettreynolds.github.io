## Meaning 1

Denotes scalar feature bundle

Core semantic features that position entities on measurable dimensions

- *tall-*: Spatial scale features
- *fast-*: Rate scale features

## Meaning 2

Denotes classificatory feature bundle

Semantic features that assign entities to categories or types

- *wooden-*: Material classification
- *French-*: Origin classification

## Meaning 3

Denotes state feature bundle

Semantic features describing temporary or permanent conditions

- *broken-*: Physical state
- *happy-*: Mental state

## Meaning 4

Denotes evaluative feature bundle

Semantic features expressing assessment or judgment

- *good-*: Quality evaluation
- *correct-*: Accuracy evaluation

## Meaning 5

Denotes reference feature bundle

Semantic features establishing identity relations between entities

- *same-*: Identity reference
- *other-*: Non-identity reference

## Projection

A common central adjective can be both pre-head and predicative, as with an angry neighbour and the neighbour is angry. Former in former president lacks the corresponding reading after be. Neither semantic property description nor a single position suffices to identify every adjective.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Words that describe things

Adjectives are words like tall, wooden or happy that say what something is like, and they don't all behave alike.

Adjectives are words such as tall, fast, wooden, French, broken, happy, good and same. This dictionary groups what they tell us into five kinds: scale (tall), type (wooden), state (broken), evaluation (good) and reference (same).

A common central adjective can come before a noun, as in an angry neighbour, and after be, as in the neighbour is angry. Not every adjective does both. The word former can come before a noun (a former president), but it doesn't have the matching use after be. So no single position or meaning picks out every adjective.

### Teacher

Gives teachers a working description of adjectives as a cluster of properties, with attention to words that don't pattern alike.

Adjective is a word category. Central members are modifiers of nouns (attributive, an angry neighbour) and predicative complements (the neighbour is angry), and gradable ones accept degree morphology (-er/-est) or degree modifiers like very. This dictionary lists five semantic groupings: scalar (tall, fast), classificatory (wooden, French), state (broken, happy), evaluative (good, correct) and reference (same, other). Classificatory adjectives resist degree modification. Some adjectives are restricted: former in former president lacks the corresponding reading after be. Fast, near and fun are listed as boundary items. This dictionary marks the analysis as provisional.
