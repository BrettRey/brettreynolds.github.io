# Anaphoric So with an Attitude Predicate

## Meaning 1

Picks up a prior proposition as the content of an attitude or utterance.

- *“Are the keys inside?” “I [think so].”*: Constructed illustration.

## Related constructions

- Compare: Anaphoric Do So (`lexical-do-so-anaphor-001`)
- Compare: Proposition Affirmation with Fronted So (`proposition-affirmation-001`)
- Alternates with: Anaphoric Not with an Attitude Predicate (`anaphoric-propositional-not-001`): I hope so and I hope not share an attitude predicate. So picks up the proposition in play. Not picks up its negative counterpart.

## Sources

- Huddleston, Rodney & Geoffrey K. Pullum (2002), The Cambridge Grammar of the English Language. Cambridge: CUP, Ch. 9 §7.2; Ch. 17 §7.7.2 (discusses; bears on projection)

## Projection

So is interpreted as the proposition that the keys are inside. Substitution of do so gives an action anaphor and fails to express that content in this frame.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: I think so

After a word like think, so can stand in for a whole statement mentioned in the conversation.

Asked Are the keys inside?, someone can answer I think so. Here so stands for the content the keys are inside. The full sentence would be I think the keys are inside.

The same short form works with hope, as in I hope so. There the pair is I hope so and I hope not: so picks up the proposition in play, and not picks up its negative counterpart. It is different from do so, which stands in for an action rather than for something that is thought or said.

### Teacher

Shows how so can pick up a proposition after an attitude predicate, as in I think so.

In this pattern so follows a licensed predicate and picks up a prior proposition as the content of an attitude or utterance. In the exchange Are the keys inside? I think so, so is interpreted as the proposition that the keys are inside. Do so gives an action anaphor, so it does not express that content in this frame. This dictionary places the pattern next to anaphoric not: I hope so and I hope not share an attitude predicate, with so picking up the proposition in play and not its negative counterpart.
