# Continuative Perfect

- id: `continuative-perfect-001`
- pattern: Clause[perfect have + past-participial VP + duration reaching the reference time]
- status: provisional analysis; evidence level: unassessed
- linguist edition: https://brettreynolds.ca/constructionary/linguist/continuative-perfect-001/
- licence: CC BY 4.0; snapshot 2026-11-19 (5c11b28)

## Meaning 1

Presents a situation as holding through an interval ending at the relevant temporal anchor.

- *Jo [has lived here since April].*: Constructed illustration.
- *Jo [had lived there since April] when we met.*: Constructed comparison. Past reference point supplied by the meeting.

## Related constructions

- A kind of: Perfect HAVE + V-en (`perfect-have-001`)
- Compare: Experiential Perfect (`experiential-perfect-001`): I’ve lived here since 2019 allows an ongoing-state reading. I’ve visited three times since 2019 counts completed episodes within the same interval.
- Interacts with: Temporal Since with a Reference Anchor (`since-time-anchor-001`): Since 2019 supplies the start time in I’ve lived here since 2019. Since also combines with experiential uses, so it does not force continuity.
- Compare: Aspectual Still and Negative Yet (`still-yet-aspectual-001`)

## Sources

- Huddleston, Rodney & Geoffrey K. Pullum (2002), The Cambridge Grammar of the English Language. Cambridge: CUP, Ch. 3 §5.2 (discusses; bears on projection)

## Projection

With a suitable stative predicate and since-anchor, the ordinary reading extends residence to the present or other reference time. An experiential perfect need only locate an occurrence before that time.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Having done something up to now

Some have-sentences say that a situation has been going on through a stretch of time that ends at the moment being talked about.

In Jo has lived here since April, Jo still lives here: the living-here stretches from April up to now. The sentence presents a situation as holding through an interval that ends at the relevant time.

That time needn't be now. In Jo had lived there since April when we met, the stretch ends at the meeting. This reading goes with a suitable state, like living somewhere, and a phrase giving the starting point. A sentence like I've visited three times since 2019 is different: it counts separate occasions rather than describing something ongoing.

### Teacher

Helps explain the ongoing-state reading of the perfect, as in has lived here since April.

The continuative perfect combines perfect have, a past-participial VP and a duration reaching the reference time. With a suitable stative predicate and a since-anchor, the ordinary reading extends the situation to the present, or to another reference time supplied by context (when we met). Contrast the experiential perfect, which only locates an occurrence before the reference time: I've visited three times since 2019 counts completed episodes within the same interval. Since does not force continuity, because it also combines with experiential uses. The analysis is provisional.
