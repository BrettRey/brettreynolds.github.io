## Meaning 1

Presents a referent as having a disposition affecting how an action can be carried out on it.

- *[This fabric washes well].*: Constructed illustration.
- *The fabric [was washed at noon].*: Constructed comparison. An eventive passive with a specific occasion, in contrast to the dispositional middle.

## Projection

The subject corresponds to the ordinary object, yet the verb is active. The default generic assessment contrasts with an event report such as This fabric was washed at noon.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Things that wash well

A sentence with an ordinary verb can describe how an action can be carried out on something.

This fabric washes well describes the fabric, and the verb washes looks like any active verb. But the sentence is about a quality of the fabric: how an action can be carried out on it. The sentence suggests someone doing the washing.

Compare The fabric was washed at noon. That reports a particular event on a particular occasion, so it isn't a statement about the fabric's qualities.
