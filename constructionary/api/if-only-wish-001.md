## Meaning 1

Expresses a wish concerning a possibility or unrealized state.

- *[If only we had brought a torch!]*: Constructed illustration.

## Related constructions

- Compare: Open and Remote If-Conditionals (`if-conditional-001`)
- Compare: Necessary Condition Only If (`only-if-restriction-001`): Only if imposes a condition, while if only can express a wish.

## Sources

- Huddleston, Rodney & Geoffrey K. Pullum (2002), The Cambridge Grammar of the English Language. Cambridge: CUP, Ch. 8 §14.2.1; Ch. 10 §10 (discusses; bears on projection)

## Projection

A consequence can remain unexpressed, and the utterance conveys a wish. In We can enter only if we bring a torch, only if instead sets a necessary condition.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: If only

If only, standing alone, expresses a wish about something that isn't the case or might not be.

If only we had brought a torch! is a wish. A result can be left unsaid, and the sentence still conveys the wish.

If only is different from only if. We can enter only if we bring a torch sets a necessary condition. If only expresses a wish, and the clause that follows is often remote in its wording.
