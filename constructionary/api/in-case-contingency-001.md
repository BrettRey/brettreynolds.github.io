## Meaning 1

Supplies the possibility against which the main action is a precaution.

- *Take a key [in case the door locks].*: Constructed illustration.

## Projection

The taking is appropriate before it is known whether the door will lock. An if-adjunct can instead make taking conditional on the door locking.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Doing something just in case

A phrase beginning with in case names a possibility that you're guarding against, so the main action is a precaution.

In Take a key in case the door locks, the part after in case names a possibility. The taking happens as a precaution against it. You don't need to know yet whether the door will lock.

That makes it different from a version with if. Take a key if the door locks makes the taking depend on the door locking. With in case, the taking is appropriate before anyone knows how things will turn out.

### Teacher

Useful for learners who treat in case as interchangeable with if.

The pattern is a prepositional phrase made of in case plus a finite clause. It supplies the possibility against which the main action is a precaution. The main action is appropriate before it is known whether the possibility will come about. An if-adjunct can instead make the main action conditional on that possibility. So the two forms invite different readings of the same main clause, as in Take a key in case the door locks versus Take a key if the door locks. The dictionary marks this dictionary as provisional and relates it to the general prepositional phrase and to if-conditionals.
