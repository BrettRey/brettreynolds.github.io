# Integrated Relative Modifier

- id: `integrated-relative-modifier-001`
- pattern: Nominal[... antecedent ... + relative clause containing a linked gap]
- status: provisional analysis; evidence level: unassessed
- linguist edition: https://brettreynolds.ca/constructionary/linguist/integrated-relative-modifier-001/
- licence: CC BY 4.0; snapshot 2026-11-19 (5c11b28)

## Meaning 1

Adds a clause to the nominal description of a referent or set of referents.

A nominal containing a relative can describe a subset, as with the books Kim bought. It can also add a property of a referent already uniquely identified. Wh-marking, that, and bare forms can package the link. Bare finite relatives generally permit an object gap but exclude a gap in the subject position of the relative clause itself.

- *The books [that Kim bought] are on the desk.*: Constructed object relative. The books Kim bought has a bare variant.
- *The books [that arrived today] are on the desk.*: Constructed subject relative. Omitting that here does not give the same integrated NP.

## Projection

An integrated relative can be bare with a close object gap but normally needs a marker with a gap as its immediate subject. Restriction of reference is a frequent interpretation.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: The books that Kim bought

A clause can be attached to a noun to help say which things you mean, as in the books that Kim bought.

In The books that Kim bought are on the desk, the part that Kim bought is joined directly to books. It helps pick out which books: the ones Kim bought. The word that can be left out here, giving the books Kim bought.

Other cases need the marker. In The books that arrived today are on the desk, the books themselves are what arrived, and omitting that doesn't give the same kind of phrase. A relative clause can also add a fact about something already identified, so it needn't narrow things down.
