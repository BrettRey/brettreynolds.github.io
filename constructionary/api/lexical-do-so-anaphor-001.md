- *Kai tied the bundle, and [did so] again the next day.*: Constructed illustration.

## Projection

Do so can be infinitival in promised to do so, and in its ordinary use favours an action antecedent. Stranded auxiliary do has a wider range of antecedents.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Do so standing in for an action

Do so can replace a phrase that has already named an action, so the speaker doesn't have to repeat it.

In Kai tied the bundle, and did so again the next day, did so stands in for tied the bundle. Instead of repeating the action, the speaker points back to it.

This works as a phrase in its own right, so it can appear in different forms. In She promised to do so, it follows to. In its ordinary use, do so looks back to an action that was named earlier. This dictionary has a separate entry on a related pattern, where the helper word do is left standing with the rest unsaid, as in Jo did too, and that one allows a wider range of earlier phrases.

### Teacher

Helps explain do so as a stand-in for an earlier action phrase, and how it differs from stranded auxiliary do.

Do so is an anaphoric expression that functions as a VP in its own right. It refers back to an earlier action, so in Kai tied the bundle, and did so again the next day, did so picks up tied the bundle. Because it's a VP, it can be infinitival, as in promised to do so. Its ordinary use favours an action antecedent. Stranded auxiliary do, the pattern in Jo did too, has a wider range of antecedents. This analysis is provisional.
