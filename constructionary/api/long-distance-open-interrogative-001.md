## Meaning 1

Questions a dependent associated with a predicate inside an embedded clause.

- *[Which tool did Lee say Jo had borrowed?]*: Constructed illustration.
- *[Which tool did Jo borrow?]*: Constructed comparison. Local counterpart. The same interrogative is associated directly with the main verb.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: A question word reaching into a later clause

A question word at the front of a sentence can ask about something that belongs to a verb in a later clause.

In *Which tool did Lee say Jo had borrowed?* the question word phrase sits at the front, but the tool is what Jo borrowed, not what Lee said. The question reaches into the clause that follows *say*.

Compare the shorter *Which tool did Jo borrow?* Here the question phrase is tied directly to the main verb. In the longer version, the same link is stretched across another clause.

Not every sentence of this kind sounds equally natural. How well it works depends on the construction in between, and experiments find gradient effects, linked to how strongly the embedded content is backgrounded.

### Teacher

For advanced classes: how a question phrase at the front is understood as belonging to a verb in a lower clause.

A long-distance open interrogative fronts an interrogative phrase and associates it with a gap inside an embedded clause. In *Which tool did Lee say Jo had borrowed?*, the tool is interpreted as the object of *borrowed*. The local counterpart, *Which tool did Jo borrow?*, ties the phrase directly to the main verb. Licensing varies with the intervening construction, and experiments report gradient effects associated with how strongly the embedded content is backgrounded. This dictionary marks the analysis as provisional, so don't present a simple rule for which embeddings allow it.
