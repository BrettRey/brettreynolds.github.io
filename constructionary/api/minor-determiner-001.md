# Minor Determiner (Plain NP/PP)

## Meaning 1

Non-determinative phrase realizes determiner function in a restricted set of NP types

- *what size hat*: Plain NP determiner in interrogative
- *this size shoes*: Measure NP determiner
- *over thirty ties*: PP determiner in measure NP

## Constraints

- (syntactic) Restricted to specific NP types (interrogatives, measure/quantity frames).

## Related constructions

- A kind of: Determination (`determination-001`)
- Compare: Property-Value NP in a Nominal (`np-property-value-001`)

## Projection

*What size hat* asks for the hat’s size, whereas *over thirty hats* sets a lower boundary on their number. Those slots license different phrases even though neither is an ordinary bare determinative lexeme.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Whole phrases that sit before a noun

In a few frames, a phrase such as *what size* or *over thirty* can come before a noun the way a small word like *the* or *some* does.

In *what size hat*, the words *what size* ask about the hat. In *this size shoes*, *this size* tells us which size of shoes. In *over thirty ties*, *over thirty* sets a lower limit on how many ties. Each of these opening groups is a whole phrase, not a single small word, yet it works in the slot before the noun where words like *the* and *some* work.

This dictionary treats the pattern as restricted. It shows up in questions about size and in frames that measure or count, so it doesn't turn any phrase at all into an opener for a noun.

### Teacher

For advanced classes, phrases rather than single words that fill the determiner slot in a few frames such as *what size hat*.

Determiner is a function; determinatives like *the* and *some* are the words that fill it elsewhere. Here the function is filled by a phrase instead: a plain noun phrase (*what size*, *this size*) or a prepositional phrase (*over thirty*) before the noun. This dictionary's pattern is a noun phrase or prepositional phrase plus a noun, and it is restricted to certain noun-phrase types: interrogatives and measure or quantity frames. *What size hat* asks for the hat's size. *Over thirty ties* sets a lower boundary on the number of ties. Present it as a limited set of frames, not as a general rule.
