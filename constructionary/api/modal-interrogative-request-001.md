## Meaning 1

Uses interrogative form to request the addressee’s action.

- *[Could you lower the shade?]*: Constructed illustration.

### Curious reader: Questions that are really requests

A yes-or-no question with can, could, will or would and you can be a way to ask someone to do something.

Could you lower the shade? has the form of a question, but the speaker wants the shade lowered. The listener can satisfy it by doing that, rather than by answering yes or no.

The pattern is a yes-or-no question with can, could, will or would and you as the subject. The same words can also be a real question. If the setting is a test of what someone is able to do, Could you lower the shade? can invite an answer about ability instead.

### Teacher

Useful for teaching requests: the interrogative form with a modal and you asks for action.

The pattern is a polar interrogative with can, could, will or would and a second-person subject, used to request the addressee's action. The same form can also be a literal question; the use differs. Could you lower the shade? can be satisfied by lowering the shade. In a capacity-testing context the same form can invite an answer about ability. Teachers can contrast it with the imperative, which this dictionary lists as a related construction. This dictionary classes the pattern as pragmatic: it concerns how the form is used.
