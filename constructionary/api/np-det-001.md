## Meaning 1

Nominal with a determiner function, forming an NP marked as definite or indefinite

- *the new car*: Definite determinative realization
- *one new car*: Indefinite determinative realization
- *Ally's new car*: Genitive NP realizing determiner function
- *what size hat*: Plain NP determiner in interrogatives

## Constraints

- (syntactic) Determiner function is a dependent in NP structure.
- (structural) Singular count nominals generally require determination; bare plural and non-count nominals can be determinerless in some contexts.

## Projection

Holding the target size fixed, that size shoes and shoes that size can share a property specification. Only the first puts the property NP before the head in determiner function in CGEL’s analysis.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Noun phrases that start with a pointing or counting word

Some noun phrases begin with a small word or phrase that tells us which one or how much.

In the new car, the word the points to a car we can pick out. In one new car, the word one counts it. In Ally's new car, Ally's does the same job, and in what size hat, the words what size ask about the hat.

The words that do this are all in the same slot in front of the rest of the phrase. Singular nouns like car generally need something there. Plural nouns and non-count nouns can sometimes go without it.

### Teacher

Shows that the determiner slot can be filled by different kinds of words and phrases, not only the and a.

In a determined NP, a determiner function is filled in front of a nominal, and the NP is marked as definite or indefinite. The determiner can be realized by a determinative (the, one), by a genitive NP (Ally's), or by a plain NP in interrogatives (what size hat). Singular count nominals generally require determination; bare plural and non-count nominals can be determinerless in some contexts. Following CGEL, determinative is a word category and determiner is a function. The dictionary marks this account as provisional.
