# Property-Value NP in a Nominal

- id: `np-property-value-001`
- pattern: NP[Det:NP[property value] + Nom] or Nom[N + Mod:NP[property value]]
- status: provisional analysis; evidence level: unassessed
- linguist edition: https://brettreynolds.ca/constructionary/linguist/np-property-value-001/
- licence: CC BY 4.0; snapshot 2026-11-19 (ef810bb)

## Meaning 1

Uses an NP to supply or ask for the value of a property of the head noun’s referent.

The dependent NP supplies both a property and a value, as in *shoes that size*. In *what size hat*, the value is the requested information. CGEL analyzes the pre-head NP as determiner and the post-head NP as modifier. This entry records the shared interpretation. The lexical range of each position and the relation to predicative *my age* remain open.

- *[what size hat]*: The interrogative NP asks for a value.
- *They don’t stock [that size shoes].*: CGEL's pre-head variant.
- *They don’t stock [shoes that size].*: CGEL's preferred post-head variant for this example.
- *[a house that size and that price]*: Coordinated post-head property specifications in a building-code hearing.

## Projection

The dependent is interpreted as a property with a value to match or supply, in either of CGEL's two positions.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Asking for and giving a size

A noun phrase like *that size* can sit before or after another noun to say which value of some property we mean.

In *what size hat*, the words *what size* ask for the size of the hat. In *They don't stock shoes that size*, the words *that size* say which size of shoes. Each one names a property (size) and, in the answer, a value for it.

The phrase can go before the noun, as in *that size shoes*, or after it, as in *shoes that size*. The second is the preferred wording for this example. Two values can be given together: *a house that size and that price*.
