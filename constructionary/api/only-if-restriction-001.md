## Meaning 1

Restricts the circumstances in which a consequence holds or a permission applies.

- *We’ll go [only if the ferry runs].*: Constructed illustration.

## Projection

The ferry running is required for going. Its running alone need not guarantee going, since further conditions can remain open.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Only if as a requirement

Only if says that something has to be the case for a consequence to hold or a permission to apply.

In We'll go only if the ferry runs, the ferry running is required for going. Without it, we don't go.

That doesn't mean the ferry running is enough on its own. Other conditions can remain open, so the ferry might run and we might still stay home. This dictionary describes only if as restricting the circumstances in which a consequence holds or a permission applies, and treats it as a more specific kind of if sentence.

### Teacher

Explains only if as marking a necessary condition, not a guarantee.

A main clause plus only if plus a finite clause restricts the circumstances in which a consequence holds or a permission applies. In We'll go only if the ferry runs, the ferry's running is required for going. Its running alone need not guarantee going, since further conditions can remain open. This dictionary treats the pattern as a specialization of the if-conditional and relates it to even if. This dictionary marks the analysis as provisional.

### Child

We'll go only if the ferry runs. What if the ferry runs?

Only if names something that has to be true. If the ferry doesn't run, we don't go. But other things might still matter, so running isn't a promise.
