# Open Let Imperative

## Meaning 1

Presents a wish, stipulation, or instruction involving the referent of the post-let NP.

- *[Let everyone draw a ticket].*: Constructed illustration.

## Related constructions

- A kind of: Imperative Clause (`imperative-clause-001`)

- Compare: Inclusive Let’s Imperative (`lets-inclusive-001`)

## Sources

## Projection

The expected action is attributed to everyone, and the sentence need not request permission from a gatekeeper. Inclusive let’s has a separate person interpretation.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Let everyone draw a ticket

A sentence starting with let can state a wish or instruction about whoever the noun phrase after let refers to.

Let everyone draw a ticket tells us what everyone is to do. The action is attributed to everyone, and the sentence doesn't need to be a request for permission from someone in charge.

It can state a wish, a rule or an instruction involving whoever the noun phrase after let refers to. This dictionary separates it from let's, which has a different person interpretation, and from the let that means giving permission.
