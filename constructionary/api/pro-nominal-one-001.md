## Projection

Ones can take plural morphology and an adjective. It normally recovers count nominal content, while the separate numeral one can answer a question about cardinality.

### Curious reader: One and ones standing in for a noun

The words one and ones can stand in for a noun that was already mentioned, so we don't repeat it.

In I preferred the larger ones, the word ones picks up a description from earlier, such as shoes or cups. It carries that description, and it can still take its own the, an adjective like larger, and a plural ending.

This dictionary says it normally stands in for something countable. The number word one is a separate thing: it can answer a question about how many. This dictionary marks the account as provisional.

Pro-nominal one(s) is an anaphoric head that recovers a nominal description while allowing independent determination and number. In I preferred the larger ones, ones can take plural morphology, a determiner (the) and an adjective (larger). It normally recovers count nominal content. The numeral one is separate and can answer a question about cardinality.
