# Proposition Affirmation with Fronted So

- id: `proposition-affirmation-001`
- pattern: Clause[so + Subject + finite auxiliary]
- status: provisional analysis; evidence level: unassessed

## Meaning 1

Confirms or acknowledges the proposition just put into play.

- *“You did promise.” “[So I did].”*: Constructed illustration.
- *“You did promise.” “[So did Jo].”*: Constructed comparison. Inversion instead adds Jo as another promiser.

## Related constructions

- Compare: Anaphoric So with an Attitude Predicate (`anaphoric-propositional-so-001`)
- Compare: Auxiliary-Stranding VP Ellipsis (`auxiliary-vp-ellipsis-001`)

## Projection

The same subject normally resumes the prior assertion, with subject before auxiliary. Inverted so did I typically adds a parallel case instead.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: So I did

Starting a short reply with so, then the subject and a helping verb, confirms what someone just said.

If someone says You did promise, a reply of So I did agrees with them: yes, that's true. The reply confirms the point just made.

Changing the order changes the meaning. So did Jo doesn't confirm that you promised; it adds Jo as another person who promised. The same subject normally resumes the earlier statement when it comes before the helping verb. This dictionary marks the account as provisional.

### Teacher

Shows how word order after so distinguishes confirming a statement from adding another person.

Fronted so with a subject before the finite auxiliary (So I did) confirms or acknowledges the proposition just put into play. With subject-auxiliary inversion (So did Jo) the meaning changes: Jo is added as another subject who did the same thing.
