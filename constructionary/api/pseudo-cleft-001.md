# Pseudo-Cleft

- id: `pseudo-cleft-001`
- pattern: Clause[Subject:NP[fused relative] + be + PredComp:XP[value]], or reversed alignment
- status: provisional analysis; evidence level: unassessed
- linguist edition: https://brettreynolds.ca/constructionary/linguist/pseudo-cleft-001/

## Meaning 1

Specifies the value of a variable defined by a fused relative.

The fused relative in What I need is a long cool drink defines what is to be identified. The value can precede be in the reversed version. Clausal values are common, including a bare or to-infinitival when the relative has do. A copular clause that evaluates what they did as a disgrace is ascriptive and does not specify the action.

- *[What I need is a long cool drink.]*: The drink supplies the value of what I need.
- *[A long cool drink is what I need.]*: Reversed alignment.
- *[What you must do is apply for special leave.]*: Bare infinitival value. To is also possible here.

## Projection

A do pseudo-cleft can take an infinitival value which the corresponding it-cleft generally excludes.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: What I need is...

A sentence can start with a what clause, then a form of be, and finish with the thing being named.

In What I need is a long cool drink, the first part sets up a gap: what is it that I need? The last part fills it in: a long cool drink. Putting the answer last gives it emphasis.

The order can be flipped, as in A long cool drink is what I need. The answer can also be an action, as in What you must do is apply for special leave. This dictionary marks the account as provisional.
