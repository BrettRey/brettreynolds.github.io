## Meaning 1

Identifies the bearer of a nominal description by appending a name without a supplementary break.

- *The [river Wye] flooded.*: Constructed illustration.

## Projection

Both parts concern the same river. A name replacement changes the referent identified. An ordinary modifier like *river water* gives no comparable identification.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: A name added right after a description

A name can follow a descriptive noun with no pause, so the two together pick out one particular thing.

In *The river Wye flooded*, *river* describes the thing and *Wye* names it. There's no comma or break between them, so the two sit together as one unit. Both parts are about the same river.

Swapping the name changes which river you mean. That's what makes this different from an ordinary describing word: *river water*, for example, doesn't name the particular river in the same way. This dictionary marks the analysis as provisional.

### Teacher

Helps explain a name attached to a descriptive noun without a supplementary break.

The pattern is a Nom made of a descriptive noun plus a proper-name expression that identifies the referent: *the river Wye*. Because there's no supplementary break, the name is integrated into the phrase. Both parts concern the same river, and replacing the name changes the referent identified. An ordinary modifier, such as *river* in *river water*, gives no comparable identification. This dictionary treats the pattern as a specialization of the Nom, and marks the analysis as provisional.
