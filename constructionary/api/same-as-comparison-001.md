## Meaning 1

Compares items for identity of referent or identity of relevant type.

- *We chose [the same model as Lee].*: Constructed illustration.

## Related constructions

- Compare: Scalar Equative *as … as* (`equative-as-as-001`)

## Projection

*The same model* can identify a shared model without asserting that we bought one and the same physical object. *As* supplies the standard of comparison.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Being the same as something else

*The same* followed by *as* compares two things and says they match.

In We chose the same model as Lee, the phrase after *as* is the standard we compare with. The two choices are the same model, but we needn't have bought one and the same physical object. It means the kind matches.

So *the same* can point to a shared kind of thing or to a single shared thing. The word *as* introduces what we compare against. This dictionary marks the analysis as provisional.
