# Intensifying So with a Nominal

- id: `so-nominal-predication-001`
- pattern: Clause[Subject:NP + be + PredComp:[stressed so + nominal expression]]
- status: provisional analysis; evidence level: unassessed

## Meaning 1

Attributes a conspicuous degree of a quality associated with the nominal expression.

In you’re so glass half full today, the final expression makes a description such as optimism available to be graded. A familiar name can work similarly when speakers associate the bearer with a style or quality. A name in this use can contribute associated qualities while retaining its independent use to identify its bearer in other contexts. The construction does not settle the lexical category of every filler.

## Projection

Stressed so in the predicative frame makes a degree interpretation available even with an expression that elsewhere names an individual or describes a situation.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: So plus a noun to mean a quality

With stress on so, a noun or name can work like a describing word that you can have a lot of.

In It's so college, the word college isn't naming a place. It stands for a quality we associate with college, and so tells us there's a lot of it. In You're so glass half full today, the expression makes an optimistic attitude available to be graded.

A familiar name can work this way too, as in This is so Obama!, when speakers link the person with a style or quality. The name still names its bearer in other settings. This dictionary marks the analysis as provisional.
