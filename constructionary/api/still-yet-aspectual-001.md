## Meaning 1

Locates persistence or non-occurrence against an expected course of events.

- *The alarm [hasn’t stopped yet].*: Constructed illustration.

## Projection

Not yet says that stopping has failed to occur up to the reference point and can suggest it remains expected. Still can instead present the existing state as persisting.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Still and not yet

Not yet and still place something against an expected course of events: one reports what hasn't happened, the other what carries on.

In The alarm hasn't stopped yet, hasn't and yet together set the stopping against a point in time, here the present, and say it hasn't happened by then. Together they can also suggest that the stopping is still expected to come.

Still works from the other side. It can present a state that already exists as carrying on. So not yet reports something that hasn't happened, and the word still reports something that continues.

This dictionary marks the analysis as provisional and illustrates it with a single constructed example, so take it as a first sketch.
