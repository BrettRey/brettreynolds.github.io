## Meaning 1

States a proviso under which a proposal or promise holds.

- *You can use the room [provided that you lock up].*: Constructed illustration.

## Related constructions

## Projection

In a permission context the phrase gives a condition on permission. It does not report the locking as already true.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Giving permission on one condition

Provided that adds a condition under which a promise or permission holds.

In You can use the room provided that you lock up, the last part sets a condition. Locking up is the condition on permission to use the room.

The phrase doesn't say that locking up has already happened. It sets a condition on the permission. The word that can be left out: provided you lock up works the same way in the pattern.

This dictionary marks the analysis as provisional; it rests on one constructed illustration.

### Child
