## Meaning 1

Adds a second description or identification of a discourse referent.

- *Lee, [our treasurer], signed the form.*: Constructed illustration.

## Projection

The second NP can be set off prosodically and contributes its own identification or characterization. Removing it leaves the anchor available for the same matrix role.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: A second description added to a name

A second noun phrase beside the first adds another way of identifying the same person or thing.

In *Lee, our treasurer, signed the form*, *our treasurer* refers to the same person as *Lee*. It adds a second description to a person already named.

The added phrase can be set off in speech by its own rhythm, and it contributes its own identification or characterization. If you take it out, *Lee signed the form* still works with the same role in the sentence.

This dictionary marks the analysis as provisional and rests on one constructed illustration.
