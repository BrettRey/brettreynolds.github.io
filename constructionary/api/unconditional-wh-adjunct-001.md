## Meaning 1

Makes the main claim hold across values for an open variable.

- *[Whatever Jo suggests], we need a vote.*: Constructed illustration.

## Projection

The adjunct does not fill a nominal argument role. The main claim is to hold across suggestions, unlike an object fused relative denoting the suggestion itself.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Whatever happens, the same thing holds

A phrase beginning with a question word, or one with ever added, says the main claim holds across all the possible answers.

In Whatever Jo suggests, we need a vote, the first part doesn't name one suggestion. It covers whatever suggestion Jo might make, and the main claim holds across all of them. We need a vote whichever suggestion it is.

This differs from a phrase that stands for the suggestion itself, as in We accepted whatever Jo suggested. There, whatever Jo suggested names the thing accepted. In the pattern here, the opening phrase doesn't fill a role like that. It sets the range of cases over which the main claim is true.
