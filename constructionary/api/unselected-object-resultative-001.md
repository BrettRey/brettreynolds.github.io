# Resultative with a Nonselected Object

- id: `unselected-object-resultative-001`
- pattern: VP[V + NP[not the ordinary object of V] + result predicate]
- status: provisional analysis; evidence level: unassessed
- linguist edition: https://brettreynolds.ca/constructionary/linguist/unselected-object-resultative-001/
- licence: CC BY 4.0; snapshot 2026-11-19 (ef810bb)

## Meaning 1

Licenses an affected participant through a result predicate, including when the base verb normally takes no such object.

- *The neighbours [shouted the baby awake].*: Constructed illustration.
- *The neighbours [shouted at the baby].*: Constructed comparison. An addressee reading is possible without attributing a change of state to the baby.

## Projection

The baby need not be an addressee of shouting. The result requires an affected participant, and dropping *awake* removes that reading. This goes beyond the reflexive-only subtype in the CGEL comparison.

## Reader editions (draft, AI-assisted, unreviewed; the linguist entry is the reference)

### Curious reader: Verbs that get an object they wouldn't normally take

A result word can let a verb take an object that the verb alone wouldn't take, so the object is changed by the action.

In *The neighbours shouted the baby awake*, the verb *shouted* is used with an object, the baby. The baby need not be the one being shouted at. What matters is the result: the baby ends up awake.

Compare *The neighbours shouted at the baby*. Here the baby can be the one addressed, and nothing says the baby changes. Drop *awake* from the first sentence and the affected-baby reading goes with it. The result word is what gives the baby its role.

The dictionary marks this account as provisional.
