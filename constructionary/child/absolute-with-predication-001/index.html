In "With the shutters closed", what is closed?

This page is an early sketch, so there’s more still to find out about this pattern.

Some sentences start with with, then a thing, then how that thing is. With the shutters closed tells us the shutters are shut. It sets the scene for the rest of the sentence.

Examples

  • With the shutters closed, the room stayed cool.
  • With the lights off, we watched the film.
