For young readers

When do you say this one and when do you say that one?

This page is an early sketch, so there’s more still to find out about this pattern.

Words like this and that help you point out one thing. You might use this for something close and that for something farther away. For more than one, say these or those.

Examples

  • Could you pass me that blue folder over there?
  • I'll take these shoes.

Play

Put two toys on a table, one close and one far. Ask a friend to pass one using this or that. Then add more toys and use these and those.
