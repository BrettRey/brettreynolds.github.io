For young readers

If pens are two dollars each, how much is one pen?

This page is an early sketch, so there’s more still to find out about this pattern.

Each and apiece tell the price of one thing. The tickets cost six dollars apiece means one ticket costs six dollars. The talk around it tells you which things.

Examples

  • The tickets cost six dollars apiece.
  • The pens cost two dollars each.

Play

Set up a pretend shop. Give each thing a price using each or apiece. Then tell a friend what three of them would cost.
