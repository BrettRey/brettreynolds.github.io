What word shows how you feel about something that happened?

This page is an early sketch, so there’s more still to find out about this pattern.

A word like fortunately can start a sentence. It shows how the speaker feels about what happened. Fortunately, the backup worked.

Examples

  • Fortunately, the backup worked.
  • Luckily, the rain stopped.
