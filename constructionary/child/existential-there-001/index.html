For young readers

Does the word there in There are two spare seats point to a place?

This page is an early sketch, so there’s more still to find out about this pattern.

Some sentences start with there just to introduce something. There are two spare seats. The seats are the news. You can ask about them too: Is there a seat?

Examples

  • There are two spare seats.
  • Is there a seat?
  • There is a cat on the roof.

Play

Look around the room. Say what you can find with There is or There are. Then turn each one into a question starting with Is there or Are there.
