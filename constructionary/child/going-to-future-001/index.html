Is It's going to rain about a trip?

This page is an early sketch, so there’s more still to find out about this pattern.

Going to can talk about what is coming next. It's going to freeze tonight tells us what to expect. Nobody is travelling. I'm going to the station is different, because there you go to a place.

Examples

  • It's going to freeze tonight.
  • I'm going to the station.
