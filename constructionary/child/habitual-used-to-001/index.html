How do you talk about how things were?

This page is an early sketch, so there’s more still to find out about this pattern.

Used to talks about how things were in the past. The shop used to close at noon.

Examples

  • The shop used to close at noon.
  • Jo used to own it.

Play

Tell a partner two things that used to be true for you. Start each with I used to.
