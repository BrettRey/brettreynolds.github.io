How do you say what you wish had happened?

This page is an early sketch, so there’s more still to find out about this pattern.

If only can show a wish. If only we had brought a torch! means we wish we had one. It's a wish, so no other part is needed.

Examples

  • If only we had brought a torch!

Play

Think of a wish about something that didn't happen. Begin with If only and say it with feeling.
