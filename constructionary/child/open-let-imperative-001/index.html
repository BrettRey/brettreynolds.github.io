For young readers

Let everyone draw a ticket. Who is going to draw one?

This page is an early sketch, so there’s more still to find out about this pattern.

This sentence tells what everyone should do. It's an instruction or a wish about them. Let's is a different pattern.

Examples

  • Let everyone draw a ticket.
  • Let each player pick a card.

Play

Make up rules for a game that start with Let. Who does each rule say should act?
