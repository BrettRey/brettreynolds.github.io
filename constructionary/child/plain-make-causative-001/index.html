When something makes you laugh, who is the one laughing?

This page is an early sketch, so there’s more still to find out about this pattern.

Make can be followed by a name and then a plain verb. The joke made Lee laugh. Lee is the one who laughs. If you start with Lee, you add to: Lee was made to laugh.

Examples

  • The joke made Lee laugh.
  • They made Kai wait.
  • Lee was made to laugh.

Play

Make up sentences with made, a name and a plain verb. Then turn each one around so it starts with the name, and add to.
