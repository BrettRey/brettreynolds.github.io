For young readers

How can you talk about some things again without saying the same word twice?

This page is an early sketch, so there’s more still to find out about this pattern.

The word ones can stand in for a word we've already used. If we're talking about shoes, we can say the larger ones. It means the larger shoes.

Examples

  • I preferred the larger ones.
  • We kept the red ones.

Play

Name a group of things, like pencils. Then say which ones you like using ones, such as the sharp ones.
