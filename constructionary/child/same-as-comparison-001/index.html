For young readers

How can two people have the same lunch?

This page is an early sketch, so there’s more still to find out about this pattern.

The same ... as tells you two things match. We chose the same model as Lee. We each chose that kind, so they match.

Examples

  • We chose the same model as Lee.
  • She ordered the same soup as Ravi.

Play

Look at a friend's bag, shoes or lunch. Say what's the same using the same ... as.
