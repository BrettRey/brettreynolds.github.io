When did something start? How do you say it?

This page is an early sketch, so there’s more still to find out about this pattern.

Since tells when a long stretch of time began. They've lived abroad since the factory closed. The closing was the start.

Examples

  • They've lived abroad since the factory closed.
  • We've been friends since 2015.

Play

Say how long you've done something using since and the day it began, like since my birthday.
