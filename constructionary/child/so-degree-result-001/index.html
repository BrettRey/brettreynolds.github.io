How would you show that something was REALLY hot?

This page is an early sketch, so there’s more still to find out about this pattern.

You can say how much by saying what happened. The street was so narrow that the van couldn't turn. The result shows how narrow it was.

Examples

  • The street was so narrow that the van couldn't turn.
  • The soup was so hot that she couldn't eat it.
