How long ago did you last eat?

This page is an early sketch, so there’s more still to find out about this pattern.

Ago counts backwards from now. Four days ago means four days before now. The time measure goes before ago.

Examples

  • The review arrived four days ago.
  • My bike broke two days ago.

Play

Say something that happened today, yesterday and last week using ago. Count backwards from now with a friend.
