For young readers

What would you do if you missed the last bus?

This page is an early sketch, so there’s more still to find out about this pattern.

What if raises something that might happen. What if the last bus has already gone? Then we talk about what we could do.

Examples

  • What if the last bus has already gone?
  • What if it snows tomorrow?

Play

Take turns asking a What if question. The other player says what they would do.
