Describing the place instead of the crowd

A busy scene can be described through the things doing the activity or through the place where it happens.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

You can report the same scene in two ways. One starts with what is doing the activity: Bees swarmed in the courtyard. The other starts with the place: The courtyard swarmed with bees. In the second, the courtyard is the subject of the sentence, and the bees come in a phrase beginning with.

The second way presents the scene as a state of the place, rather than as something the bees are doing. This dictionary treats that analysis as provisional. It also notes that only suitable verbs allow the place-first form, so it can't be assumed to work wherever the other does.

Examples

  • The courtyard swarmed with bees.
  • Bees swarmed in the courtyard.

Try it

Take a sentence that says what something is doing in a place. Can you turn it round so the place comes first and the sentence says what the place is full of?
