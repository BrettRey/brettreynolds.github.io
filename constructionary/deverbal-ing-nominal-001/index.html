Activity nouns ending in -ing

Some words in -ing name an activity or its result and behave like nouns, taking words like careful and of.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In The careful sorting of the files took hours, sorting names an activity, but it acts like a noun. It takes the adjective careful in front of it, and the files comes after of.

The same idea can be said another way. Carefully sorting the files uses the adverb carefully, and the files follows the verb directly. Here the -ing word acts like a verb. This dictionary treats the two patterns as different, and the first as a noun pattern.

Examples

  • The careful sorting of the files took hours.

Try it

Compare careful sorting of the files with carefully sorting the files. Which one has of? Which one has an adverb?
