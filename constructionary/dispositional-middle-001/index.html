Things that wash well

A sentence with an ordinary verb can describe how an action can be carried out on something.

This fabric washes well describes the fabric, and the verb washes looks like any active verb. But the sentence is about a quality of the fabric: how an action can be carried out on it. The sentence suggests someone doing the washing.

Compare The fabric was washed at noon. That reports a particular event on a particular occasion, so it isn't a statement about the fabric's qualities.

Examples

  • This fabric washes well.
  • The fabric was washed at noon.

Try it

Think of an object around you and a verb for something done to it. Can you say how well it does under that action, as in This fabric washes well?
