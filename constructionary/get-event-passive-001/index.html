Got promoted

Using got with a past-participle word, as in Jo got promoted, presents someone as undergoing something that happened to them.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In Jo got promoted last week, something happened to Jo: someone promoted her. The sentence puts the spotlight on the change and on what it means for Jo.

The plain version, Jo was promoted, can describe the same event. This dictionary says that got foregrounds the change or its relevance to Jo, while was also covers cases that describe a state, such as is widely believed. A good outcome is possible too, so the pattern doesn't need to be about something bad.

Examples

  • Jo got promoted last week.
  • Jo was promoted last week.

Try it

Take a sentence like The window was broken and try it with got. Does the focus shift?
