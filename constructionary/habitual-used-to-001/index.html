Used to

Used to followed by a plain verb describes a habit or a state that belonged to a past period.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

The shop used to close at noon tells us that closing at noon was the regular pattern at some earlier time. Used to can also describe a past state, as in Jo used to own it.

The present-tense counterpart, use to, doesn't parallel this by describing a current habit in an ordinary affirmative sentence.

Examples

  • The shop used to close at noon.
  • Jo used to own it.
