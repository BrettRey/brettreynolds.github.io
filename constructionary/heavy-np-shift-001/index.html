Saving the long part for last

When one part of a sentence is long, it can be placed after a shorter part of the same verb.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In She handed to the chair a folder containing all the amended exhibits, the long phrase a folder containing all the amended exhibits comes last. The short phrase to the chair comes before it, even though both belong to the same verb.

This dictionary says the order depends on how long the phrase is and on how much is already known about it. A short word in that spot gives a strongly degraded result: handed to the chair it doesn't work well. So the pattern suits a bulky phrase.

Examples

  • She handed to the chair a folder containing all the amended exhibits.

Try it

Think of a sentence where you have to describe something long, such as a folder containing all the amended exhibits. Where do you put it?
