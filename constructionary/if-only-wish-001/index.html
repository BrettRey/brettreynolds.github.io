If only

If only, standing alone, expresses a wish about something that isn't the case or might not be.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

If only we had brought a torch! is a wish. A result can be left unsaid, and the sentence still conveys the wish.

If only is different from only if. We can enter only if we bring a torch sets a necessary condition. If only expresses a wish, and the clause that follows is often remote in its wording.

Examples

  • If only we had brought a torch!
  • We can enter only if we bring a torch.

Try it

Think of something you wish had gone differently. Start the sentence with If only.
