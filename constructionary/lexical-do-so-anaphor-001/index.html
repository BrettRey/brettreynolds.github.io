Do so standing in for an action

Do so can replace a phrase that has already named an action, so the speaker doesn't have to repeat it.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In Kai tied the bundle, and did so again the next day, did so stands in for tied the bundle. Instead of repeating the action, the speaker points back to it.

This works as a phrase in its own right, so it can appear in different forms. In She promised to do so, it follows to. In its ordinary use, do so looks back to an action that was named earlier. This dictionary has a separate entry on a related pattern, where the helper word do is left standing with the rest unsaid, as in Jo did too, and that one allows a wider range of earlier phrases.

Examples

  • Kai tied the bundle, and did so again the next day.
  • She promised to do so.
