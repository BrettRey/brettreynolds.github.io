Adjectival Passive

adjectival-passive-001 · syntactic · provisional

Clause[Subject + be/seem/remain + AdjP[past-participial base]]

Early sketch: one example so far, and the evidence for the analysis isn’t written up yet.

Meaning

Predicates a state or property through an adjective with passive-like morphology.

  • The door remained locked.Constructed illustration.

Related constructions

A kind of

  • Subject-Oriented Ascriptive Predicative

Compare

  • Verbal Be-PassiveThe door remained locked supports an adjective analysis. The door was locked by security at noon permits the verbal passive analysis with an event time and a by-phrase.

Sources

  • Huddleston, Rodney & Geoffrey K. Pullum (2002), The Cambridge Grammar of the English Language. Cambridge: CUP, Ch. 16 §10.1.3. discussed · bears on projection

Kind and projectibility

What recognizing it lets you predict

Remain can select the stative predicate. A verbal passive with an agent and an explicitly dated event gives an event reading rather than the state interpretation illustrated here.
