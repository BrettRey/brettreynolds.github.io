Degree

degree-001 · provisional

XP[{more|less} + X] | XP[X + -er] | XP[{most|least} + X] | XP[X + -est] | XP[as + X + as]

Meaning

Meaning 1

Denotes relative scale position

Semantic features encoding comparative, superlative and equative scale relations

  • taller/shorter than; more/less expensive thanBidirectional comparison
  • tallest/shortest; most/least expensiveScale endpoints
  • as tall asScale equality

Meaning 2

Denotes scale intervals

Semantic features encoding degree of difference between scale points

  • much taller/slightly shorterRelative intervals
  • two feet taller/three times lessMeasured intervals

Meaning 3

Denotes comparison classes

Semantic features encoding reference sets for comparison

  • taller than average/most expensive of allSet comparison
  • as tall as expected/least expensive optionStandard comparison

Kind and projectibility

What recognizing it lets you predict

The same dimension can have an explicit differential in two centimetres wider and a simple comparative in wider. An equality comparison can instead supply a standard with as wide as. The constructions test comparison structure separately from the particular scale chosen.

Evidence for the projection

CGEL discusses equality and inequality and separates differential modification from the standard phrase.

Confidence: medium.

Stable: the profile recurs. Provisional.

Core properties

  • Scale comparison morphology/periphrasis (-er/-est; more/most; as X as)
  • Degree modification of gradable predicates (compatible with gradable adjectives/adverbs)

Peripheral properties

  • Measure phrase integration (two inches taller; three times as X)
