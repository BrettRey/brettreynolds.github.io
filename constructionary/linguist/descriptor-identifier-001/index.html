Descriptor + Identifier Label

descriptor-identifier-001 · mixed · provisional

NP[descriptor + identifier: number, letter name, or alphanumeric code]

Meaning

Identifies a bearer by an assigned label within a naming system.

The descriptor gives the kind of bearer. The following identifier picks out a bearer within the relevant naming system. Gen in Gen Z supplies the kind in the same way as Ward in CGEL’s Ward 17. Descriptor describes a contribution within the naming construction. In CGEL an embellishment is a semantically nonrestrictive dependent accompanying a proper name. The shared pattern leaves the syntactic head and the identifier’s word category open.

Compare

  • Strong Proper Name ConstructionRoom 101 and Kim both occur as bare argument NPs. In Room 101 the noun supplies the type of bearer and the assigned code supplies its identity.
  • Title with a Personal NameDr Patel also places a nominal before an identifying form. Dr is an appellation giving the bearer’s status in a personal name. Room in Room 101 gives the type of entity and the following code is interpreted within the site.
  • Integrated Appositive NameCompare Room 101 with the river Wye. Both pair a type expression with an identifier. The latter has an overt determiner and is analyzed as an integrated appositive. The comparison leaves the headedness of Room 101 open.

Kind and projectibility

What recognizing it lets you predict

A descriptor can be followed by a number, a letter or a mixed code in the same naming role. Changing a label may change the bearer, or leave it fixed if the two labels are aliases. Any quantity or rank associated with the code depends on the local allocation convention.

Evidence for the projection

Cornell uses Room 101 and Room 302A, and gives Multipurpose Room A for the same space as Room 302A. CGEL gives Ward 17. Pew uses Gen Z as a cohort label.

Confidence: medium.

Evidence level: not yet assessed (stable, networked, maintained or controlled). Provisional.

Boundary cases

  • In 101 rooms, 101 determines how many rooms. In Room 101, it identifies a room.
  • In a type specification such as a type A personality, the designation supplies a class inside an ordinary count NP. Compare bare Gen Z for an identified cohort.
