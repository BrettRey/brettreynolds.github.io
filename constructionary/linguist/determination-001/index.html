Determination

determination-001 · syntactic · provisional

Determiner function in NP

Meaning

Licenses a nominal as an NP and marks it for definiteness or indefiniteness

Realized by basic determiners (determinatives), subject-determiners (genitive NPs), and a limited set of minor determiners (plain-case NPs or PPs).

  • the new carDeterminative realization; definite
  • one new carDeterminative realization; indefinite
  • Ally's new carGenitive NP realizing determiner function
  • what size hatPlain NP determiner in interrogatives
  • over 20 timesPP determiner in a measure NP

Constraints

  • syntactic Determiner is a dependent within NP structure.
  • structural Singular count nominals generally require determination; bare plural and non-count nominals can be determinerless, and a small set of bare singular count frames are licensed (institutional/time/iteration).

Kind and projectibility

What recognizing it lets you predict

The slot can be filled by the DP this or by a genitive NP such as Jo’s. The relation holds in this book and Jo’s book though the dependent belongs to a different category.

Evidence for the projection

CGEL separates determiner function from determinative category and documents multiple realizations.

Confidence: medium.

Stable: the profile recurs. Provisional.

Core properties

  • Determiner slot realization licensing NP (determiner-obligatoriness-singular-count)
  • Deital distributional profile (existential-there-pivot; partitive-of-complement; identificational-hosting; one-substitution)

Peripheral properties

  • Tendency to align with semantic definiteness (identifiability; uniqueness; anaphoric-recoverability)
