Long-Distance Open Interrogative

long-distance-open-interrogative-001 · mixed · provisional

fronted interrogative XPᵢ + clause containing a subordinate clause with gapᵢ

Meaning

Questions a dependent associated with a predicate inside an embedded clause.

  • Which tool did Lee say Jo had borrowed?Constructed illustration.
  • Which tool did Jo borrow?Constructed comparison. Local counterpart. The same interrogative is associated directly with the main verb.
