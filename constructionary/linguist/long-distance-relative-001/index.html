Long-Distance Dependency in an Integrated Relative

long-distance-relative-001 · mixed · provisional

antecedent nominal + relative with an antecedent-linked gap inside an embedded clause

Meaning

Identifies a referent by a dependency that crosses into an embedded predication.

  • We need the tool which Lee said Jo had borrowed.Constructed illustration.
  • We need the tool which Jo borrowed.Constructed comparison. Local counterpart with no intervening clause.

Kind and projectibility

What recognizing it lets you predict

The tool fills the object role of borrowed. The relative and a corresponding question differ in their discourse functions, and the acceptability of both depends on the intervening construction.
