Proper Noun

n-proper-001 · syntactic · provisional

N[proper]

Meaning

Meaning 1

Denotes individual-specific feature bundle

Core semantic features characterizing a particular individual

  • Einstein-Features of Einstein-ness
  • Shakespeare-Features of Shakespeare-ness

Meaning 2

Denotes archetypal feature bundle

Characteristic semantic features that can ground metaphorical extension

  • Waterloo-Defeat-related features
  • Marathon-Endurance-related features

Meaning 3

Denotes institutional feature bundle

Semantic features associated with institutional entities

  • Harvard-University-related features
  • Congress-Legislative-related features

Meaning 4

Denotes geographical feature bundle

Semantic features associated with locations

  • Pacific-Ocean-related features
  • Everest-Mountain-related features

Dimensions

Form
Noun specialized to head proper names; morphologically simple or compound. Normally written with an initial capital, subject to lexical and stylistic exceptions.
Meaning
Individual-specific, archetypal, institutional, or geographical features
Function
Head of proper NP; licenses bare NP without determiner
Distribution
Heads Nom in proper NPs; modifier position in N-N compounds

What recognizing it lets you predict

Proper noun and proper name need not have the same extent. New Zealand is a multiword name, and a noun normally used as a name can appear in an explicitly descriptive NP such as another Einstein.

Evidence for the projection

CGEL separates the word category from the whole designation and documents secondary uses.

Confidence: medium.
