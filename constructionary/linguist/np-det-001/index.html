Determined Noun Phrase

np-det-001 · syntactic · provisional

NP[Det Nom]

Meaning

Nominal with a determiner function, forming an NP marked as definite or indefinite

  • the new carDefinite determinative realization
  • one new carIndefinite determinative realization
  • Ally's new carGenitive NP realizing determiner function
  • what size hatPlain NP determiner in interrogatives

Constraints

  • syntactic Determiner function is a dependent in NP structure.
  • structural Singular count nominals generally require determination; bare plural and non-count nominals can be determinerless in some contexts.

Related constructions

A kind of

  • Noun PhraseAn overt determiner combines with the nominal.

Kinds of this

  • Deictic Demonstrative Determination
  • Indefinite NP with a Modified Personal Name
  • Personal Determination with we or you
  • Positive Paucal a few and a little
  • Predeterminer all before a Determined NP

Implements

  • DeterminationThe overt determiner in the new car, a new car, and Jo’s new car realizes the determiner function.

Overlaps with

  • Adjectivally Modified Personal Pronoun NP
  • Common Noun Phrase
  • Definite NP ConstructionThe book satisfies both patterns. A book has a determiner and is indefinite. A referential bare name such as London can be definite.
  • Indefinite NP ConstructionA book satisfies both patterns. The book has a determiner and is definite. The bare NP dogs in We saw dogs can be indefinite.

Kind and projectibility

What recognizing it lets you predict

Holding the target size fixed, that size shoes and shoes that size can share a property specification. Only the first puts the property NP before the head in determiner function in CGEL’s analysis.

Evidence for the projection

CGEL provides the matching property-value forms and treats non-determinative realizations as restricted.
