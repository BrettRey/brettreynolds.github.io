Pro-Nominal One and Ones

pro-nominal-one-001 · syntactic · provisional

Nom[one/ones as anaphoric head + optional nominal dependents]

Early sketch: one example so far, and the evidence for the analysis isn’t written up yet.

Meaning

Recovers a nominal description while allowing independent determination and number.

Kind and projectibility

What recognizing it lets you predict

Ones can take plural morphology and an adjective. It normally recovers count nominal content, while the separate numeral one can answer a question about cardinality.
