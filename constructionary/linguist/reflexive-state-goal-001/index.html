State Goal with a Construction-Licensed Reflexive

reflexive-state-goal-001 · mixed · provisional

VP[V + reflexive direct object + PP denoting a resulting state]

Early sketch: one example so far, and the evidence for the analysis isn’t written up yet.

Meaning

Extends a goal expression to a state caused by an activity whose verbal head need not otherwise license the reflexive object.

  • The child cried herself to sleep.Constructed illustration.

Related constructions

A kind of

  • Caused-Motion ConstructionA state is construed as a goal.

  • Direct-Object Reflexive Anaphor

Kind and projectibility

What recognizing it lets you predict

To sleep describes the state reached, not the destination of an actual motion. Omitting the PP removes the interpretation that licenses the reflexive object after cry.
