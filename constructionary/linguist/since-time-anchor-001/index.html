Temporal Since with a Reference Anchor

since-time-anchor-001 · mixed · provisional

PP[since + date/NP/finite clause] with a later reference time

Early sketch: one example so far, and the evidence for the analysis isn’t written up yet.

Meaning

Supplies the earlier boundary of the interval under discussion.
