Specificational Copular Clause

specificational-copular-001 · mixed · provisional

Clause[variable NP + be + value XP]

Meaning

Identifies a value for a description made salient by the other copular expression.

  • The main obstacle is the permit.Constructed illustration.
  • The permit is the main obstacle.Constructed comparison. The reversed copular order identifies the same obstacle.

Kind and projectibility

What recognizing it lets you predict

The permit supplies a value rather than a general property. The reverse order can preserve the identification while changing the informational packaging.
