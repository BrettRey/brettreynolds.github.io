Conditional provided that

sufficiency-provided-that-001 · mixed · provisional

conditional PP[provided (that) + finite clause]

Early sketch: one example so far, and the evidence for the analysis isn’t written up yet.

Meaning

States a proviso under which a proposal or promise holds.

  • You can use the room provided that you lock up.Constructed illustration.

Kind and projectibility

What recognizing it lets you predict

In a permission context the phrase gives a condition on permission. It does not report the locking as already true.
