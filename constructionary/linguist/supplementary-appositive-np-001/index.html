Supplementary Appositive NP

supplementary-appositive-np-001 · mixed · provisional

anchor NP + supplementary NP with a co-referential interpretation

Early sketch: one example so far, and the evidence for the analysis isn’t written up yet.

Meaning

Adds a second description or identification of a discourse referent.

  • Lee, our treasurer, signed the form.Constructed illustration.

Kind and projectibility

What recognizing it lets you predict

The second NP can be set off prosodically and contributes its own identification or characterization. Removing it leaves the anchor available for the same matrix role.
