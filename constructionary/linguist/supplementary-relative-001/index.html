Supplementary Relative

supplementary-relative-001 · mixed · provisional

anchor + supplementary wh-relative clause

Early sketch: one example so far, and the evidence for the analysis isn’t written up yet.

Meaning

Adds a separate predication about a referent or a larger anchor.

  • Jo visited Bath, which she had never seen before.Constructed illustration.

Kind and projectibility

What recognizing it lets you predict

The clause can add information about an already identified referent. Substituting bare that-relative syntax generally fails in the same supplementary reading.
