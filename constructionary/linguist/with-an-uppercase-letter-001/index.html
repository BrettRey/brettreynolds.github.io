With an Uppercase Letter Construction

with-an-uppercase-letter-001 · semantic · provisional

with + an + uppercase + Letter-name

Meaning

Implements Letter-Case Specification Construction, meaning 1: Specifies uppercase orthography for the relevant label using uppercase.

  • internet with an uppercase I.Institutional or official sense.
  • reformation with an uppercase R.Proper or historical event sense.

Kind and projectibility

What recognizing it lets you predict

When the contrast is literal, uppercase I specifies the same letter shape as capital I. In a spelling instruction this does not tell the listener whether the word is a name. The comparison concerns the literal case instruction.

Evidence for the projection

The dictionary verifies the written-case contrast. The uppercase substitution is a constructed use.

Confidence: medium.
