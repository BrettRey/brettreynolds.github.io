Choosing the better description with more than

More ... than can compare two descriptions of the same thing and say which one fits better.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In The proposal was more optimistic than realistic, the speaker is weighing two labels for the same proposal and saying that optimistic fits better than realistic.

Here there is one thing, the proposal, and two competing descriptions of it. The descriptions don't have to share a numerical scale, yet they can still be compared for how well each one describes the thing.

Examples

  • The proposal was more optimistic than realistic.
  • The meal was more filling than tasty.

Try it

Think of something you've seen or eaten. Can you say which of two descriptions fits it better, using more ... than?
