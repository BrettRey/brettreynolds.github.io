Whole phrases that sit before a noun

In a few frames, a phrase such as what size or over thirty can come before a noun the way a small word like the or some does.

In what size hat, the words what size ask about the hat. In this size shoes, this size tells us which size of shoes. In over thirty ties, over thirty sets a lower limit on how many ties. Each of these opening groups is a whole phrase, not a single small word, yet it works in the slot before the noun where words like the and some work.

This dictionary treats the pattern as restricted. It shows up in questions about size and in frames that measure or count, so it doesn't turn any phrase at all into an opener for a noun.

Examples

  • what size hat
  • this size shoes
  • over thirty ties
