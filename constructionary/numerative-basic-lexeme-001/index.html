Number words from zero to ninety-nine

The number words from zero to ninety-nine each work as a single unit, with no internal parts that can be joined or described.

Five, ten, twelve, nineteen, forty and twenty-six all count as one word each. Even twenty-six is a single unit, not a phrase.

The evidence points to the same thing. Twenty-four gives twenty-fourth, which changes the whole unit. A number like three hundred twenty-four is different: it has extra structure, and in the right context a shorter version can recover the missing parts.

Examples

  • five
  • twelve
  • forty
  • twenty-six
