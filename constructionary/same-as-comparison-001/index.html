Being the same as something else

The same followed by as compares two things and says they match.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In We chose the same model as Lee, the phrase after as is the standard we compare with. The two choices are the same model, but we needn't have bought one and the same physical object. It means the kind matches.

So the same can point to a shared kind of thing or to a single shared thing. The word as introduces what we compare against. This dictionary marks the analysis as provisional.

Examples

  • We chose the same model as Lee.
  • She ordered the same soup as Ravi.
