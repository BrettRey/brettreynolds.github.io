Giving permission on one condition

Provided that adds a condition under which a promise or permission holds.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In You can use the room provided that you lock up, the last part sets a condition. Locking up is the condition on permission to use the room.

The phrase doesn't say that locking up has already happened. It sets a condition on the permission. The word that can be left out: provided you lock up works the same way in the pattern.

This dictionary marks the analysis as provisional.

Examples

  • You can use the room provided that you lock up.
  • You can play outside provided that you wear a coat.

Try it

Give someone permission to do something, then add provided that and a condition. Does the condition sound like it has already happened?
