A which clause that adds extra information

A which clause after a name can add a separate piece of information about it.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In Jo visited Bath, which she had never seen before, the which clause adds a second statement. It tells us something more about Bath, a place already identified. It doesn't help us work out which place is meant.

A which clause can also add information about a larger anchor than a single noun. This dictionary notes that swapping in a bare that-relative generally fails to give the same added-information reading.

This dictionary marks the analysis as provisional and rests on one constructed illustration.

Examples

  • Jo visited Bath, which she had never seen before.

Try it

Add a which clause after the name of a place you know, and say what extra information it gives.
