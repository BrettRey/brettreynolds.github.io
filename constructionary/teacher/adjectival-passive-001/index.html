Adjectival Passive

Helps students tell a state described by an adjective (remained locked) from a verbal passive event (was locked by security).

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

In the adjectival passive, a past-participle form heads an adjective phrase after be, seem or remain, and the clause ascribes a state or property to the subject. Remain supports the adjective analysis because it can select the stative predicate. A verbal passive with an agent and an explicitly dated event, such as The door was locked by security at noon, permits the verbal analysis and gives an event reading instead. This dictionary treats the adjectival passive as a specialization of the subject-ascriptive pattern and marks the analysis as provisional.

Terms

Both patterns use a past-participial form. This dictionary calls the first an adjectival passive (adjective phrase) and the second a verbal be-passive.

Examples

  • The door remained locked.

Contrasts to teach

  • The door remained locked.State of the door; adjective analysis supported.
  • The door was locked by security at noon.Agent and dated event; verbal passive analysis permitted.

Watch for

  • A learner might read every past participle after be, seem or remain as an event with an agent, when remained locked describes a state.
  • A learner might assume seem or remain can't be followed by locked, when the pattern allows be, seem and remain.

In class

Students get sentence pairs built on the same participle, one with remain and one with a by-phrase and a time. They label each as state or event and say what clue decided it.
