Anaphoric Not with an Attitude Predicate

Shows how not can pick up a negative proposition after an attitude predicate, as in I hope not.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

In this pattern not follows a licensed predicate and picks up the negative counterpart of a proposition already in the discourse. In the exchange Is the screen broken? I hope not, not supplies the content that the screen is not broken. I don't hope so can instead negate the hoping. Whether the standalone not is compatible depends on the predicate, so each predicate has to be checked. This dictionary relates it to negative raising.

Terms

Not here is anaphoric: it picks up the negative counterpart of an earlier proposition. This dictionary names the pattern anaphoric not with an attitude predicate.

Examples

  • “Is the screen broken?” “I hope not.”

Contrasts to teach

  • I hope not.Not supplies the content that the screen is not broken.
  • I don't hope so.Can instead negate the hoping.

Watch for

  • A learner might read I hope not as saying the speaker doesn't hope, when not supplies the negative content that is hoped for.
  • A learner might assume every attitude predicate can be followed by standalone not, when compatibility varies by predicate.

In class

Students ask each other yes-or-no questions and answer with I hope so and I hope not. They then write out the full sentence each short answer stands for.
