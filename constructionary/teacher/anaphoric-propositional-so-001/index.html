Anaphoric so with an Attitude Predicate

Shows how so can pick up a proposition after an attitude predicate, as in I think so.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

In this pattern so follows a licensed predicate and picks up a prior proposition as the content of an attitude or utterance. In the exchange Are the keys inside? I think so, so is interpreted as the proposition that the keys are inside. Do so gives an action anaphor, so it does not express that content in this frame. This dictionary places the pattern next to anaphoric not: I hope so and I hope not share an attitude predicate, with so picking up the proposition in play and not its negative counterpart.

Terms

So is anaphoric here: it refers back to a proposition. This dictionary names the pattern anaphoric propositional so.

Examples

  • “Are the keys inside?” “I think so.”

Contrasts to teach

  • I hope so.So picks up the proposition in play.
  • I hope not.Not picks up its negative counterpart.

Watch for

  • A learner might take so as meaning also or very, when it picks up a whole proposition as content.
  • A learner might swap in do so for so, when do so gives an action anaphor.

In class

Students ask each other yes-or-no questions and answer with I think so and I hope so. They then write out the whole sentence that so stands for.
