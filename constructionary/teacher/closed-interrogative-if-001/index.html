Subordinate Closed Interrogative with if

Useful for separating if that introduces an embedded question from conditional if, and for contrasting if with whether.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

Interrogative if introduces a finite subordinate closed interrogative clause in licensed complement positions. The embedded clause has embedded-question interpretation and ordinary subject-verb order. Conditional if is different: in If Jo was ready, we could leave, the if-clause makes readiness a condition on the main clause. Interrogative if cannot introduce a whether-to infinitival.

Terms

Subordinate closed interrogative: an embedded yes/no question. Compare whether, which is related; see this dictionary's entry on whether.

Examples

  • I wondered if Lee had arrived.

Contrasts to teach

  • They asked if Jo was ready.Embedded question.
  • If Jo was ready, we could leave.Condition on the main clause.

Watch for

  • A learner might read the if in asked if Jo was ready as a condition.
  • A learner might expect if to introduce a to-infinitival the way whether can.

In class

Give students sentences with if. They sort them into embedded question (asked if Jo was ready) and condition (If Jo was ready, we could leave) and say how they decided.
