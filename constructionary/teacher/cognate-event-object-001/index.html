Cognate Event Object

Useful for explaining objects that repeat the verb's event noun and add manner or duration.

How to explain it

In a cognate event object, an object noun phrase whose head is an event nominal related to the verb elaborates the event the verb already describes. It can occur with otherwise intransitive verbs such as die. In died a long and agonising death, the object adds duration and manner without introducing a second dying event, and in fought a heroic fight the nominal elaborates the fight. The object is internal to the verb phrase. A reaction object differs: it identifies what is expressed rather than describing the verbal event.

Terms

Cognate object is the traditional name. Od is the direct object.

Examples

  • He died a long and agonising death.
  • She fought a heroic fight.

Contrasts to teach

  • She fought.Verb alone.
  • She fought a heroic fight.The event noun adds a description of the same fighting.

Watch for

  • A learner might read died a long and agonising death as two events, dying and a death.
  • A learner might treat the object as a separate participant, when it describes the verb's own event.

In class

Give students bare verbs such as fought and died. They add an event noun related to the verb plus describing words, then say what the added words tell about the event.
