Deverbal Noun in -er

Helps explain agent and instrument nouns in -er and the of-phrase that matches the verb's object.

How to explain it

A deverbal noun in -er names a participant characteristically associated with the action of the base verb. The central reading identifies the person who does the activity (singer). Instrument readings occur with forms such as mixer. With many agent nouns, the verb's object has a corresponding of-phrase, as in the reviewer of the manuscript. The same ending in islander supports a separate noun-base pattern, so not every -er word comes from a verb.

Terms

Traditional grammars call the person-naming ones (singer) agent nouns; instrument readings such as mixer are a further reading of the same pattern. This dictionary treats the result as an ordinary common noun.

Examples

  • the reviewer of the manuscript
  • a mixer

Watch for

  • A learner might assume every -er noun names a person, when mixer names an instrument.
  • A learner might read islander as built on a verb, when its base is a noun.

In class

Students match verbs (sing, review, mix) to -er nouns, then say whether each names a person or a tool, and add an of-phrase to the people words where it fits.
