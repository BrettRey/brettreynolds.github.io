Distributive Rate with Each or Apiece

Helps explain apiece and each after an amount as a rate assigned to each member of a group.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

A measure or counted NP followed by each or apiece assigns the stated amount to each unit or participant, with the group supplied by context. In The tickets cost six dollars apiece, six dollars is the rate per ticket. The pattern is related to indefinite rates and to floating distributives.

Terms

This dictionary labels the pattern a distributive rate.

Examples

  • The tickets cost six dollars apiece.
  • The pens cost two dollars each.

Contrasts to teach

  • The tickets cost six dollars apiece.The amount applies to each ticket.
  • The tickets cost six dollars altogether.A total for the group, for contrast.

Watch for

  • A learner might read six dollars apiece as the total for all the tickets.
  • A learner might look for the group in the amount phrase, when context supplies it.

In class

Students write price tags for a class shop using each or apiece, then a partner states the total for three items.
