Concessive Conditional even if

Helps explain how even if differs from a plain if in conditional sentences.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

An even-if adjunct (even if plus a finite clause) holds the main clause's consequence fixed under a condition presented as unfavourable or extreme. It is a specialization of the if-conditional. The sentence can be used while the condition is still uncertain: Even if it rains, we'll go doesn't need the rain to be settled. The plan is presented as holding in that case, unlike the ordinary expectation a bare conditional suggests. This dictionary marks the analysis as provisional, with medium confidence, and rests on CGEL's discussion of concessive conditionals.

Terms

Concessive conditional is the name used here for even if clauses.

Examples

  • Even if it rains, we'll go.
  • Even if you're late, we'll wait for you.

Contrasts to teach

  • Even if it rains, we'll go.The plan holds even in the unfavourable case.
  • If it rains, we'll go.A bare conditional, with the ordinary expectation this dictionary mentions.

Watch for

  • A learner might read even if as a plain if with extra emphasis, and miss that the consequence is presented as holding regardless.
  • A learner might think the speaker of Even if it rains, we'll go knows that it will rain.

In class

Give pairs a plan ("We'll start at noon") and a possible obstacle (heavy traffic, a late guest). Each pair writes one sentence with even if and one with a plain if, then explains aloud what changes.
