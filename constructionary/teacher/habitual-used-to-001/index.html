Habitual Used To

Helps students use used to for past habits and states and see how it differs from the present.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is used to plus a plain-form verb: The shop used to close at noon. It presents a habitual situation or state as characteristic of a past period, so it covers habits and states: Jo used to own it. This dictionary says the present counterpart use to does not express a parallel current habit in ordinary affirmative clauses. It treats it as a specialization of VP structure, related to the past tense, and marks the analysis as provisional.

Terms

Often taught as the past habitual or used to + infinitive.

Examples

  • The shop used to close at noon.
  • Jo used to own it.

Watch for

  • A learner might use use to for a present habit in an affirmative sentence, when it doesn't parallel used to.
  • A learner might think used to covers only repeated actions, when it also covers states like owning.

In class

Students write two sentences with used to about how their town has changed, one a habit and one a state, then swap and decide which is which.
