Teacher

Optative if only

Teaches learners to express a wish with if only, and to tell it from only if.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

Optative if only stands alone with a finite clause, often modally remote: If only we had brought a torch! It expresses a wish concerning a possibility or unrealized state. A consequence can remain unexpressed, and the utterance conveys a wish. Only if instead sets a necessary condition, as in We can enter only if we bring a torch. This dictionary relates the pattern to ordinary if-conditionals and marks the analysis as provisional.

Terms

Optative is this dictionary’s term for the wish use.

Examples

  • If only we had brought a torch!
  • We can enter only if we bring a torch.

Contrasts to teach

  • If only we had brought a torch!A wish.
  • We can enter only if we bring a torch.A necessary condition.

Watch for

  • A learner might treat if only as the same as only if, when if only expresses a wish and only if imposes a condition.
  • A learner might look for a main clause after if only, when the consequence can remain unexpressed.

In class

Give students situations where something went wrong. They write a wish with If only and a related condition with only if, and say how the two differ.
