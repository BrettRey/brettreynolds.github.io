Teacher

Precautionary In Case

Useful for learners who treat in case as interchangeable with if.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is a prepositional phrase made of in case plus a finite clause. It supplies the possibility against which the main action is a precaution. The main action is appropriate before it is known whether the possibility will come about. An if-adjunct can instead make the main action conditional on that possibility. So the two forms invite different readings of the same main clause, as in Take a key in case the door locks versus Take a key if the door locks. The dictionary marks this dictionary as provisional and relates it to the general prepositional phrase and to if-conditionals.

Terms

Sometimes described as a precautionary or contingency use of in case. The if version is a conditional adjunct.

Examples

  • Take a key in case the door locks.
  • Bring an umbrella in case it rains.

Contrasts to teach

  • Take a key in case the door locks.Precaution; taken before it's known whether the door will lock.
  • Take a key if the door locks.Taking depends on the door locking.

Watch for

  • A learner might treat in case and if as having the same meaning in Take a key in case the door locks.
  • A learner might think the in case clause describes something that has already happened.

In class

Give pairs of sentences that differ only in in case and if. Students say what you would do, and when, in each version, then write their own pair.
