Incongruity what is X doing Y?

Covers the idiomatic What is X doing Y? question that asks for an explanation of something presented as odd.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is an interrogative built from what, a form of be, a subject, doing and then a location or an -ing expression. Its meaning is to ask for an explanation of a state, presence or action presented as anomalous. A ladder in a hall need not be performing an action, so the doing isn't literal. The same string shape with a human subject and an activity can also support an ordinary literal what-question, so the shape alone doesn't settle which reading is meant. This dictionary treats it as a specialization of the open interrogative clause and marks it provisional. It cites discussion in CGEL, in Kay and Fillmore, and in Goldberg.

Terms

Sometimes called the What's X doing Y? construction.

Examples

  • What’s that ladder doing in the hall?
  • What's your bike doing on the lawn?

Contrasts to teach

  • What's that ladder doing in the hall?Asks why it's there, presented as odd.
  • What's Dad doing in the hall?Can be an ordinary question about an activity.

Watch for

  • A learner might answer What's that ladder doing in the hall? by describing an action the ladder performs.
  • A learner might not realize the speaker is presenting the situation as strange.

In class

Place a few out-of-place objects around the room. Students ask What's the X doing Y? about each, and a partner supplies an explanation.
