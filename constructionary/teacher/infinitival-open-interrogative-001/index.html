Infinitival Open Interrogative

Covers embedded questions such as which route to take, which have a question phrase and a to-infinitival.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is an interrogative phrase followed by a to-infinitival with a linked gap. It presents an unresolved choice about an envisaged action. In They discussed which route to take, which route supplies the missing object of take, and the action is prospective or modal. The corresponding finite question can ask instead what was actually done. This dictionary treats the pattern as a specialization of the open interrogative clause and relates it to for-infinitivals. It is provisional.

Terms

Sometimes called an infinitival wh-question or an embedded infinitival interrogative.

Examples

  • They discussed which route to take.
  • She asked where to park.

Contrasts to teach

  • They discussed which route to take.An envisaged action, still undecided.
  • They discussed which route they took.A finite question can ask what was actually done.

Watch for

  • A learner might read which route to take as asking about a past action.
  • A learner might treat which route as separate from the verb take, when it supplies the missing object of take.

In class

Students complete sentences that start with I don't know, using a question word plus to and a verb. They then rewrite each with a finite clause and compare the meanings.
