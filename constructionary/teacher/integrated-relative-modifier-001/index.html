Integrated Relative Modifier

Explains relative clauses that are part of a noun phrase and help identify its referent.

How to explain it

The pattern is a nominal containing an antecedent plus a relative clause with a linked gap. It can describe a subset, as in the books Kim bought, or add a property of a referent already uniquely identified. Wh-marking, that and bare forms can package the link. Bare finite relatives generally permit an object gap but exclude a gap in the subject position of the relative clause itself. So an integrated relative can be bare with a close object gap but normally needs a marker when the gap is its immediate subject. Restriction of reference is a frequent interpretation. This contrasts with the supplementary relative, as in The books, which arrived yesterday, are upstairs. This dictionary marks the analysis as provisional.

Terms

Traditionally called a restrictive relative clause. This dictionary says integrated, since integration is distinct from semantic restriction, and calls the other kind supplementary (traditionally non-restrictive).

Examples

  • The books that Kim bought are on the desk.
  • The books that arrived today are on the desk.

Contrasts to teach

  • The books that arrived today are on the desk.Integrated, the relative helps identify the books.
  • The books, which arrived yesterday, are upstairs.Supplementary, a separate comment on books already supplied.

Watch for

  • A learner might think that must appear in every relative clause, though the books Kim bought is given as a variant.
  • A learner might think every relative clause narrows down the referent, though this dictionary says one can also add a property of a referent already uniquely identified.

In class

Students rewrite pairs of sentences into one noun phrase with a relative clause, and test which can drop that. They then compare with a comma version using which.
