Anaphoric Do So

Helps explain do so as a stand-in for an earlier action phrase, and how it differs from stranded auxiliary do.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

Do so is an anaphoric expression that functions as a VP in its own right. It refers back to an earlier action, so in Kai tied the bundle, and did so again the next day, did so picks up tied the bundle. Because it's a VP, it can be infinitival, as in promised to do so. Its ordinary use favours an action antecedent. Stranded auxiliary do, the pattern in Jo did too, has a wider range of antecedents. This analysis is provisional.

Terms

Do so can be described as a pro-form for a verb phrase. In this dictionary: anaphoric do so, with stranded auxiliary do as a separate, related entry.

Examples

  • Kai tied the bundle, and did so again the next day.
  • She promised to do so.

Contrasts to teach

  • Kai tied the bundle, and did so again the next day.Do so is a VP in its own right and looks back to an action.
  • Kai tied the bundle, and Jo did too.Stranded auxiliary do, a related pattern with a wider range of antecedents.

Watch for

  • A learner might think do so is only a finite form, when this dictionary shows it can be infinitival, as in promised to do so.
  • A learner might use do so to refer back to something that isn't an action, when its ordinary use favours an action antecedent.

In class

Students write sentences naming an action and then rewrite the second mention with do so. They then compare with a version that uses did too and say what each form refers back to.
