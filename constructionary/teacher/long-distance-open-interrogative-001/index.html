Long-Distance Open Interrogative

For advanced classes: how a question phrase at the front is understood as belonging to a verb in a lower clause.

How to explain it

A long-distance open interrogative fronts an interrogative phrase and associates it with a gap inside an embedded clause. In Which tool did Lee say Jo had borrowed?, the tool is interpreted as the object of borrowed. The local counterpart, Which tool did Jo borrow?, ties the phrase directly to the main verb. Licensing varies with the intervening construction, and experiments report gradient effects associated with how strongly the embedded content is backgrounded. This dictionary marks the analysis as provisional, so don't present a simple rule for which embeddings allow it.

Terms

Open interrogative is the term here; a wh-question is another name for the same kind of question. The link across clauses is a long-distance dependency.

Examples

  • Which tool did Lee say Jo had borrowed?

Contrasts to teach

  • Which tool did Lee say Jo had borrowed?Long-distance. The tool is the object of borrowed.
  • Which tool did Jo borrow?Local counterpart. The phrase is tied to the main verb.

Watch for

  • A learner might link the question phrase to say, when the tool is the object of borrowed.
  • A learner might expect every embedding to allow the pattern equally, when licensing varies with the intervening construction.

In class

Give students a statement like Lee said Jo had borrowed a tool. They turn it into a question about the tool, then check each question by identifying which verb the question phrase belongs to.
