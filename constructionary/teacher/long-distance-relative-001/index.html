Long-Distance Dependency in an Integrated Relative

For advanced classes: how a relative clause links a noun to a position inside a lower clause.

How to explain it

In a long-distance integrated relative, the relative contains an antecedent-linked gap inside an embedded clause. In We need the tool which Lee said Jo had borrowed, the tool fills the object role of borrowed. The local counterpart, We need the tool which Jo borrowed, has no intervening clause. The relative and a corresponding question differ in their discourse functions, and acceptability of both depends on the intervening construction. This dictionary marks the analysis as provisional, so avoid stating a simple rule for which embeddings are allowed. See also the related entry on long-distance open interrogatives.

Terms

Integrated relative is CGEL's term. A restrictive relative clause is another name for it. The link across clauses is a long-distance dependency.

Examples

  • We need the tool which Lee said Jo had borrowed.

Contrasts to teach

  • We need the tool which Lee said Jo had borrowed.Long-distance. The tool is the object of borrowed.
  • We need the tool which Jo borrowed.Local counterpart with no intervening clause.

Watch for

  • A learner might link which to said, when the tool is the object of borrowed.
  • A learner might expect every embedding to allow the pattern, when acceptability depends on the intervening construction.

In class

Students combine pairs such as We need a tool and Jo borrowed it, first locally, then with Lee said inserted. They name which verb the tool belongs to each time.
