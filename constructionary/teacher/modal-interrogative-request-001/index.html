Teacher

Modal Interrogative Request

Useful for teaching requests: the interrogative form with a modal and you asks for action.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is a polar interrogative with can, could, will or would and a second-person subject, used to request the addressee's action. The same form can also be a literal question; the use differs. Could you lower the shade? can be satisfied by lowering the shade. In a capacity-testing context the same form can invite an answer about ability. Teachers can contrast it with the imperative, which this dictionary lists as a related construction. This dictionary classes the pattern as pragmatic: it concerns how the form is used.

Terms

Indirect speech act or indirect request are textbook names for this kind of use.

Examples

  • Could you lower the shade?
  • Can you open the window?
  • Would you close the door?

Contrasts to teach

  • Could you lower the shade?A request; lowering the shade satisfies it.
  • Lower the shade.The related imperative.

Watch for

  • A learner might answer Could you lower the shade? with only yes, taking it as a question about ability.

In class

Students write three requests with can, could or would and you for a classroom situation (a closed window, a lost pen). In pairs, one reads the request and the other responds with an action, not words. Discuss when a spoken answer would be expected instead.
