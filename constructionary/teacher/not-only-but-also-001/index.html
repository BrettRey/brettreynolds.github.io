Additive Not Only and But Also

Explains not only ... but also as a way of joining two items that both hold, with the second as an addition.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

Not only X but (also) Y is a coordination construction that asserts both contributions, with the second presented as additional or noteworthy. Despite the overt not, the first contribution is included. The dictionary treats it as a specialization of ordinary coordination. When not only plus a constituent is preposed and the first coordinate is a clause, inversion can follow. The dictionary marks this account as provisional.

Terms

Sometimes called a correlative conjunction, or a correlative pair. Here it's treated as a kind of coordination.

Examples

  • She not only signed it but also delivered it.

Watch for

  • A learner might read not only as negating the first part, when the first contribution is still included.
  • A learner might drop but when building the second part.

In class

Give students pairs of simple facts about one person. They join each pair with not only and but also, then say whether both facts are true.
