Property-Value NP in a Nominal

Shows a noun phrase supplying or asking for the value of a property of a head noun's referent, before or after the noun.

How to explain it

A property-value NP supplies both a property and a value, as in shoes that size. In what size hat, the value is the requested information. CGEL analyzes the pre-head NP as determiner and the post-head NP as modifier, and this dictionary records the shared interpretation. Two values can be coordinated, as in a house that size and that price. The lexical range of each position, and the relation to predicative my age, remain open. The dictionary marks this account as provisional.

Terms

Pre-head NP in determiner function is a CGEL analysis; the post-head NP is a modifier.

Examples

  • what size hat
  • They don't stock that size shoes.
  • They don't stock shoes that size.
  • a house that size and that price

Contrasts to teach

  • They don't stock that size shoes.Pre-head variant, with the property NP in determiner function.
  • They don't stock shoes that size.Post-head variant, CGEL's preferred form for this example, with the property NP as a modifier.

Watch for

  • A learner might read that size as an ordinary determiner such as the.
  • A learner might think the pre-head and post-head versions mean different things.

In class

Give students a clothing-store role-play. They ask and answer using what size hat and shoes that size, and compare where the property phrase goes.
