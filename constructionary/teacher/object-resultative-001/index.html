Object-Oriented Resultative Construction

Explains a result state attached to the direct object, and how it differs from depictives and from state-goal PPs.

How to explain it

The object-oriented resultative is a verb with a direct object (Od) followed by a predicative complement (an AdjP or NP) that is predicated of that object. The Od is in the state the predicative names at the end of the verbal process. Unlike a depictive, a resultative entails a change culminating in that state. An optional resultative still counts as a complement, while an optional depictive such as almost raw in ate the steak almost raw is an adjunct. Marked state goals such as to sleep are locative complements. This dictionary marks the analysis as provisional.

Terms

Resultative is the traditional name. The predicative is also sometimes called an object complement. Depictive is the name for a description that holds during the event.

Examples

  • He washed it clean.
  • He painted the fence blue.
  • He talked himself hoarse.

Contrasts to teach

  • He painted the fence blue.Resultative. The fence comes to be blue as a result of the painting.
  • He ate the steak almost raw.Depictive. Almost raw describes the steak while he ate it, and it's an adjunct.
  • She cried herself to sleep.To sleep is a marked state goal, a locative complement, so it isn't a resultative predicative.

Watch for

  • A learner might read painted the fence blue as having two objects, when blue describes the fence.
  • A learner might treat cried herself to sleep as the same pattern as talked himself hoarse, when to sleep is a locative complement.
  • A learner might take almost raw in ate the steak almost raw as a result, when it describes the steak during the eating.

In class

Give students sentences with a verb, an object and a descriptive word. They ask whether the object ends up in that state because of the action (resultative) or is simply that way while the action happens (depictive), and sort them.
