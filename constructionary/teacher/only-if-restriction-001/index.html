Necessary Condition Only If

Explains only if as marking a necessary condition, not a guarantee.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

A main clause plus only if plus a finite clause restricts the circumstances in which a consequence holds or a permission applies. In We'll go only if the ferry runs, the ferry's running is required for going. Its running alone need not guarantee going, since further conditions can remain open. This dictionary treats the pattern as a specialization of the if-conditional and relates it to even if. This dictionary marks the analysis as provisional.

Terms

Necessary condition is the logical term for what only if marks. Conditional clause is the traditional name for the if part.

Examples

  • We'll go only if the ferry runs.
  • You can borrow it only if you ask first.

Contrasts to teach

  • We'll go only if the ferry runs.The ferry running is required for going.
  • We'll go if the ferry runs.Plain if, for comparison. This dictionary treats only if as a specialization of the if-conditional.

Watch for

  • A learner might think that if the ferry runs, we're sure to go, when only if doesn't say that.

In class

Students complete sentence stems that start with a consequence and only if, such as I'll come only if ___, then say what else could still stop the outcome.
