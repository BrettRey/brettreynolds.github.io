Open Interrogative Clause

Covers wh-questions, and how the role of the question word affects word order in main clauses, with subordinate clauses normally keeping subject-predicator order.

How to explain it

An open interrogative is a headed clause marked by an interrogative phrase, characteristically asking for the value of a variable. If the interrogative phrase is the Subject, it keeps basic position and there's no inversion (Who broke the window?). A non-subject interrogative phrase is normally fronted and triggers subject-auxiliary inversion in a main clause (Which report did Kim finish?). Subordinate open interrogatives normally keep Subject-Predicator order (I know which report Kim finished). A request for information is characteristic but not necessary: these clauses can also be rhetorical or convey indirect directives and evaluations. Reduced phrases such as Which one? aren't instances of this clause type.

Terms

Wh-question is the traditional name; this dictionary's term is open interrogative. Subject-auxiliary inversion is the traditional name for the change in order.

Examples

  • Who broke the window?
  • Which report did Kim finish?
  • I know which report Kim finished.
  • Why are you making such a fuss?

Contrasts to teach

  • Who broke the window?Interrogative Subject. Basic order, no inversion.
  • Which report did Kim finish?Fronted non-subject, so inversion in the main clause.
  • I know which report Kim finished.Subordinate clause, basic order retained.

Watch for

  • A learner might carry the main-clause inverted order into a subordinate question, when subordinate clauses normally retain Subject-Predicator order.
  • A learner might invert the subject and a helping verb in a question whose question word is the subject, when an interrogative subject keeps its basic position.
  • A learner might take every such question as a request for information, when it can be rhetorical.

In class

Students turn statements such as Kim finished the report into questions with who, which and why. They sort the results by whether the question word is the subject, then embed each one after I know and compare the order.
