Open Let Imperative

Explains imperatives with let plus a noun phrase and a bare infinitive, such as Let everyone draw a ticket.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is imperative let plus a non-inclusive NP plus a bare infinitival. It presents a wish, stipulation or instruction involving the referent of the NP after let. The expected action is attributed to that referent (everyone draws a ticket), and the sentence needn't request permission from a gatekeeper. Inclusive let's has a separate person interpretation. This dictionary relates the pattern to the permissive let and to let's as neighbouring constructions. This dictionary marks the analysis as provisional.

Examples

  • Let everyone draw a ticket.
  • Let the guests choose their seats.

Watch for

  • A learner might read the sentence as a request for permission from a gatekeeper, when it needn't be one.
  • A learner might read Let everyone draw a ticket as having the person interpretation of let's, when this dictionary says let's has a separate one.

In class

Students write three rules for a class game using let plus a group (everyone, each team) and a verb. They then say who is expected to act in each rule.
