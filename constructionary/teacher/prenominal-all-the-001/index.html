Predeterminer All before a Determined NP

Explains all before another determiner, as in all those shells and all the shells.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

In the pattern NP[all + Det + Nom], all applies universal quantification outside a following determiner phrase or constituent. All can precede those and the in the same NP. Each and every do not generally occupy that same position before an existing central determiner. This dictionary files this as a specialization of the noun phrase with a determiner, and relates it to each-of partitives. It is provisional, with medium confidence.

Terms

Textbooks sometimes call all in this position a predeterminer. In CGEL terms, determiner is a function and determinative a category.

Examples

  • They catalogued all those shells.
  • They catalogued all the shells.

Watch for

  • A learner might think all has to replace the determiner, when it can come before it.
  • A learner might expect each and every to take the same position before the or those.

In class

Students write six noun phrases with all plus a determiner (the, those, these, my) and a plural noun, then compare with a partner and discuss which ones they find natural.
