Preterite with Present-Time Politeness

Explains why a past-tense verb can make a present request more polite.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The preterite of a request-related predicate plus a complement can soften a present request by presenting it as an already entertained thought or intention. In I wanted to ask if a seat was available, the request is made at the time of speaking. The same morphology can also be literally past, in a context that supplies a past intention. This dictionary marks the analysis provisional, so present it as a description of this example, and point out that tense can express more than time.

Terms

Sometimes called the 'past tense of politeness' or 'tentative past'; this dictionary uses preterite for the past tense form.

Examples

  • I wanted to ask if a seat was available.

Watch for

  • A learner might take wanted as describing something that happened only in the past.
  • A learner might not realize the speaker is asking now.

In class

Students role-play asking for a seat or a favour, first with a plain request and then with a past-tense softened one, and say how each might sound to the listener.
