Proposition Affirmation with Fronted So

Shows how word order after so distinguishes confirming a statement from adding another person.

How to explain it

Fronted so with a subject before the finite auxiliary (So I did) confirms or acknowledges the proposition just put into play. With subject-auxiliary inversion (So did Jo) the meaning changes: Jo is added as another subject who did the same thing. The same subject normally resumes the prior assertion, with subject before auxiliary, and inverted so did I typically adds a parallel case instead. This dictionary marks the analysis provisional. Make the order contrast the focus.

Terms

The inverted order (so did Jo) is the pattern in 'so do I'; this dictionary treats the two orders as distinct constructions.

Examples

  • “You did promise.” “So I did.”
  • “You did promise.” “So did Jo.”

Contrasts to teach

  • “You did promise.” “So I did.”Same subject; confirms the proposition.
  • “You did promise.” “So did Jo.”Inversion adds Jo as another promiser.

Watch for

  • A learner might use So did I to confirm their own earlier action.
  • A learner might read So did Jo as agreeing that you promised.

In class

Pairs read a statement with did, such as You did promise, and take turns answering with So I did or So did another name. The partner says whether the reply confirms or adds someone.
