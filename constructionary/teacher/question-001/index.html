Question

Frames question as a meaning category (a set of possible answers) that different sentence types can carry.

How to explain it

Question is a semantic category: an expression defines a set of logically possible answers. It is not a clause type and is not the same as the act of inquiry. A closed question presents a delimited answer set (Have you seen it?), an open question contains a variable (Who broke it?), a declarative clause can carry question meaning (You're leaving?) and a reduced expression can too (Which one?, which isn't thereby a Clause). An answer supplies the missing information; a conversational response needn't. This dictionary says punctuation and word order don't fix membership, and it marks the account provisional.

Terms

This dictionary separates the clause types (closed and open interrogative) from the semantic category Question.

Examples

  • Have you seen it?
  • Who broke it?
  • You're leaving?
  • Which one?

Watch for

  • A learner might think a question must start with an auxiliary or a question word.
  • A learner might think a question mark makes something a question.
  • A learner might treat any reply as an answer, when an answer resolves the open alternatives.

In class

Give students four cards, each carrying a different question form. They list the possible answers each defines and sort replies into answers and merely appropriate responses.
