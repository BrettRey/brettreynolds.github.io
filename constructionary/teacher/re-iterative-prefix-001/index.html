Iterative Re- on a Verb

Shows how re- builds verbs meaning to perform an action again.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The prefix re- plus a suitable verbal base forms a verb describing another performance of the relevant action: Please recheck the numbers. The normal reading presupposes an earlier check. A word that merely starts with the same letters, such as reject, need not support an again analysis, so students shouldn't segment every re- word. This dictionary marks the account provisional and is built on one constructed example.

Terms

Re- is traditionally a prefix; this dictionary calls the pattern iterative re- on a verb.

Examples

  • Please recheck the numbers.

Watch for

  • A learner might split reject into re- plus ject and look for an again meaning.
  • A learner might use recheck when there was no earlier check.

In class

Students list re- verbs they know and sort them into again meanings and words where re- only appears at the start, then check each against a dictionary.
