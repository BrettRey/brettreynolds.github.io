State Goal with a Construction-Licensed Reflexive

Explains the reflexive-plus-PP frame where an activity leads to a resulting state.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is a VP with a verb, a reflexive direct object and a PP denoting a resulting state: The child cried herself to sleep. It extends a goal expression to a state caused by an activity, and the verb need not otherwise license the reflexive object. To sleep describes the state reached, not the destination of an actual motion. Omitting the PP removes the interpretation that licenses the reflexive object after cry. This dictionary notes that CGEL distinguishes these PPs from adjective and noun phrase predicatives. It's marked provisional.

Terms

Often grouped with resultative constructions; this dictionary treats it as a specialization of caused motion, with a state construed as a goal.

Examples

  • The child cried herself to sleep.

Watch for

  • A learner might read to sleep as movement to a place.
  • A learner might assume cry is an ordinary verb that takes an object.

In class

Students list activities (cry, sing, run) and complete each as a sentence with a reflexive and a state to phrase, then discuss which describe a state reached.
