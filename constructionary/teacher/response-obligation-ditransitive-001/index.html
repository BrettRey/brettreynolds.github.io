Double-Object Obligation with Owe

Helps explain owe with two objects and how an obligation differs from a transfer.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

Owe takes an indirect object (the creditor, or entitled participant) followed by a direct object (the outstanding thing): I owe Lee an apology. This dictionary treats it as a specialization of the ditransitive VP. The meaning is an obligation, not an intended gift: Lee is the person to whom the apology is owed, and the sentence can be true when the apology has not been offered. Contrast this with verbs of giving, where the pattern suggests a transfer.

Terms

Indirect object and direct object are the usual terms. In this dictionary, the pattern is a double-object construction.

Examples

  • I owe Lee an apology.
  • We owe the neighbours a favour.

Contrasts to teach

  • I owe Lee an apology.Obligation; the apology is outstanding.
  • I gave Lee an apology.A transfer, which the sentence presents as completed.

Watch for

  • A learner might read owe Lee an apology as saying the apology has already been delivered.

In class

Students write three things they owe someone (a call, a thank-you, a book) using the double-object pattern. Partners say whether each thing has been handed over yet and how they can tell.
