Scalar Endpoint Adjective in a Resultative

Helps explain resultatives whose adjective names an attainable endpoint on a scale.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

In a resultative VP like polished the railing smooth, the adjective gives the result as an attained point or region on a scale. On the completed-event reading, the rail reaches contextual smoothness. This dictionary treats the pattern as a specialization of the object resultative, and notes that replacing smooth with a property that doesn't readily supply an attainable endpoint can lower acceptability, even with the same verb and object. Present the adjective as the state the action brings about.

Terms

Traditional grammar sometimes speaks of a resultative predicate or result phrase. In this dictionary: scalar endpoint adjective in a resultative.

Examples

  • They polished the railing smooth.
  • She wiped the table clean.

Contrasts to teach

  • They polished the railing.No result is stated; compare with polished the railing smooth.

Watch for

  • A learner might read smooth in polished the railing smooth as describing how the polishing was done, when it names the state reached.

In class

Give students verb and object pairs (wipe the table, paint the fence, press the shirt). They add an adjective that names the state reached, then compare which adjectives name a clear endpoint.
