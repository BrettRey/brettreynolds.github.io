Identity Comparison with Same … As

Helps explain the same + noun + as for identity of referent or of type.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The same plus a noun, followed by an as-phrase, compares items for identity of referent or identity of relevant type. In We chose the same model as Lee, the same model can identify a shared model without asserting that we bought one and the same physical object. As supplies the standard of comparison. This dictionary relates the pattern to the equative as ... as construction, and marks the analysis as provisional.

Terms

Related in this dictionary to the equative as ... as comparison.

Examples

  • We chose the same model as Lee.
  • She ordered the same soup as Ravi.

Watch for

  • A learner might read the same model as meaning one single physical object, when it can mean the same type.
  • A learner might leave out as before the standard of comparison.

In class

Students write sentences about what they share with a partner (the same colour, the same bus) using the same ... as. Then they decide whether each shows one shared object or a shared type.
