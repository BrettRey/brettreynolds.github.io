Temporal Since with a Reference Anchor

Helps explain since as the earlier boundary of an interval, and how it differs from because.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

A PP headed by since supplies the earlier boundary of the interval under discussion, relative to a later reference time. Its complement can be a date, an NP or a finite clause. In They've lived abroad since the factory closed, the closure anchors the beginning of the relevant span. Substituting because preserves a causal interpretation in some cases but removes this temporal-bounding contribution. This dictionary treats the pattern as a specialization of the PP and marks the analysis as provisional.

Terms

Since here is a preposition in CGEL's sense, including when its complement is a clause.

Examples

  • They've lived abroad since the factory closed.
  • We've been friends since 2015.

Contrasts to teach

  • They've lived abroad since the factory closed.The closing marks the start of the span.
  • They've lived abroad because the factory closed.Because gives a reason and doesn't mark the start of the span.

Watch for

  • A learner might read since the factory closed as giving a reason, as because would.
  • A learner might leave out the later reference time that the period runs up to.

In class

Students put an event on a timeline and write one since sentence marking the start of the period. A partner draws the span from the since point to the reference time.
