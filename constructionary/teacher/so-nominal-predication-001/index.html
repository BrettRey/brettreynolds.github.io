Intensifying So with a Nominal

Helps explain stressed so before a noun or name to grade an associated quality.

How to explain it

In the frame Subject + be + stressed so + nominal expression, so invites a degree interpretation from a contextually retrieved property. The final expression makes a description, such as optimism, available to be graded. A familiar name can work similarly when speakers associate its bearer with a style or quality, while keeping its ordinary use to identify the bearer elsewhere. The pattern doesn't settle the lexical category of every filler. This dictionary marks the analysis as provisional and relates it to degree, to proper names and to stressed some exclamatives.

Terms

Intensifier so is traditional. Here it is stressed, and it grades a property associated with the nominal.

Examples

  • You're so glass half full today.
  • It's so college.
  • This is so Obama!

Watch for

  • A learner might read so college as saying that something is a college, when it characterizes the situation by a feature associated with college.
  • A learner might read so Obama as referring to the person, when it grades an associated quality.
