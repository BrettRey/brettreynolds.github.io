Specificational Copular Clause

Helps explain be-clauses that identify a value for a description.

How to explain it

A specificational copular clause pairs a variable NP with a value expression and be: it identifies a value for a description made salient by the other copular expression. In The main obstacle is the permit, the permit supplies a value rather than a general property. The reverse order, The permit is the main obstacle, can preserve the identification while changing the informational packaging. This dictionary treats the pattern as a specialization of the clause and relates it to pseudo-clefts and to subject-ascriptive clauses. The analysis is marked provisional.

Terms

Compare ascriptive clauses, which ascribe a property. In this dictionary the related pattern is subject-ascriptive.

Examples

  • The main obstacle is the permit.
  • The permit is the main obstacle.

Contrasts to teach

  • The main obstacle is the permit.The variable comes first and the value second.
  • The permit is the main obstacle.The reversed order identifies the same obstacle.

Watch for

  • A learner might read the permit as describing a property of the obstacle, when it supplies a value.
  • A learner might treat the reversed order as changing which obstacle is identified.

In class

Students write a description-then-value sentence (The winner is ...), reverse it, and say what each order puts first.
