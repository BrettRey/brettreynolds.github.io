Speech-Act Adverbial

Helps explain an adverbial that characterizes the speaker's manner or purpose in making the utterance.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

A speech-act adverbial is a supplementary adverbial oriented to the utterance act: it characterizes the speaker's manner or purpose in making the utterance. In Frankly, the repair won't last, frankly characterizes the speaker's statement, not the repair's manner of failing. A paraphrase can mention speaking frankly without changing the content asserted. This dictionary relates it to evaluative sentence adverbs and to participial clause supplements. The analysis is marked provisional.

Terms

In this dictionary: speech-act adverbial.

Examples

  • Frankly, the repair won't last.
  • Honestly, the soup needs salt.

Watch for

  • A learner might read frankly as describing how the repair fails, when it describes the speaker's statement.
  • A learner might think the adverb changes the content asserted, when a paraphrase like I'm speaking frankly leaves it unchanged.

In class

Write statements with a speech-act adverb on cards. Students paraphrase each as I'm saying this ..., and check that the asserted content doesn't change.
