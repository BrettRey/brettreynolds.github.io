Aspectual Still and Negative Yet

Useful for explaining how not yet can suggest an expected change and how still can present a continuing state.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

This dictionary covers clauses with still or a negative yet and a temporal reference point, such as now. Not yet says the event has failed to occur up to that point, and it can suggest the event remains expected. Still can instead present an existing state as persisting. Both words are heard against an expected course of events. This dictionary treats the pattern as provisional and illustrates it with one constructed example, so treat these as starting observations for a lesson, not a full account of either word.

Examples

  • The alarm hasn't stopped yet.
  • The alarm is still ringing.

Watch for

  • A learner might read not yet as a plain negative and miss that the event can still be expected.
  • A learner might treat still as only a time word and miss that it presents an existing state as continuing.

In class

Give pairs a situation, such as a kettle on the stove. Each partner writes one sentence with not yet and one with still describing it at different moments. They swap and say what each sentence suggests about what the speaker expects next.
