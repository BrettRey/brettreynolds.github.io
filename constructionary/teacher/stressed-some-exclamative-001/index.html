Exclamation with Stressed Some

Optional enrichment on exclamations with stressed some, which judge the quality of a thing rather than its quantity.

How to explain it

The pattern is an exclamation whose predicative complement is an NP with stressed SOME plus a nominal. It presents an instance as remarkable for its kind, with positive or negative evaluation. CGEL compares emotive one. A contrast from the cited work separates this from an ordinary exclamation: The wine we drank can express surprise purely at quantity, whereas That was some wine we drank resists that reading. This dictionary leaves open how far the parallel with one extends and marks the analysis provisional, so present it as a tentative description. In the examples, capitals show where the stress falls.

Terms

CGEL compares this use of some with emotive one. No other standard traditional name is given in this dictionary.

Examples

  • SOME hotel that was! An utter disgrace!
  • Those are SOME elephants!
  • That was SOME wine we drank!

Watch for

  • A learner might hear SOME in That was SOME wine as a quantity word meaning a lot of wine.
  • A learner might read the pattern as only praise, when the evaluation can be negative, as in SOME hotel that was.

In class

Students write a short exclamation about a film, a meal or a trip using stressed some. Classmates say whether the speaker is praising or complaining and point to the words that tell them.
