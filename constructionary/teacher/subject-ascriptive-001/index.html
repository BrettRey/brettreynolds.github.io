Subject-Oriented Ascriptive Predicative

Helps students see that the word after a linking verb describes the subject rather than acting as an object.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is a clause with a subject, a linking verb, and a predicative complement that attributes a property, class or condition to the subject referent. In Jo seems unusually calm, the complement describes Jo, and the corresponding stative property can often be predicated with be. An ordinary object cannot replace the adjective in the same role, which is one way to tell this complement from an object. This dictionary marks the analysis provisional and offers one constructed illustration, so use it as a starting point for classroom examples.

Terms

Predicative complement is the CGEL term; textbooks sometimes call it a subject complement. This dictionary sets it beside an object-oriented counterpart.

Examples

  • Jo seems unusually calm.
  • Jo is unusually calm.

Watch for

  • A learner might treat the word after seems as an object, when it describes the subject.
  • A learner might read seems as describing an action by Jo, when it links Jo to a description.

In class

Give students sentences with seems, looks and is plus a description. They underline the person or thing being described and swap seems for is, checking that the description still applies to the same subject.
