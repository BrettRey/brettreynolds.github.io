Conditional provided that

Useful for explaining provided that as a way to attach a condition to a permission or promise.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is a conditional PP formed from provided (that) and a finite clause. It states a proviso under which a proposal or promise holds. In a permission context the phrase gives a condition on permission: it does not report the locking as already true. This dictionary treats the whole phrase as a PP with a finite clause, one of the clause-taking prepositions. This analysis is provisional, and a separate entry covers the related unless pattern.

Terms

Sometimes called a subordinating conjunction in traditional grammar. CGEL: a preposition taking a finite clause.

Examples

  • You can use the room provided that you lock up.

Watch for

  • A learner might read provided that you lock up as saying you have already locked up.
  • A learner might think provided is only a verb, when here it introduces a condition.

In class

Students write permissions with provided that, for example about homework or the school library. A partner restates each as what you may do and what the condition is.
