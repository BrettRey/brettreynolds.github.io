Teacher

Supplementary Appositive NP

Useful for explaining added noun phrases set off by commas, such as Lee, our treasurer.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is an anchor NP followed by a supplementary NP with a co-referential interpretation. It adds a second description or identification of a discourse referent. The second NP can be set off prosodically and contributes its own identification or characterization. Removing it leaves the anchor available for the same matrix role. This dictionary marks the analysis as provisional and has one constructed illustration. Related separate entries cover a restrictive appositive name and the supplementary relative clause.

Terms

Traditional grammar sometimes calls this non-restrictive apposition. CGEL: supplementary apposition.

Examples

  • Lee, our treasurer, signed the form.

Contrasts to teach

  • Lee, our treasurer, signed the form.Supplementary NP adds a second identification.
  • Lee signed the form.With the added NP removed, the anchor still fills the same role.

Watch for

  • A learner might treat Lee and our treasurer as two different people.
  • A learner might think the added phrase is needed to complete the sentence.

In class

Students write sentences naming a person or place and adding a second description in a comma-set phrase. They test whether removing the phrase leaves a complete sentence and say what the phrase adds.
