Supplementary Relative

Helps explain which clauses that add information about an already identified referent, set off by commas.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is an anchor followed by a supplementary wh-relative clause. It adds a separate predication about a referent or a larger anchor: in Jo visited Bath, which she had never seen before, the clause adds information about Bath, an already identified referent. Substituting bare that-relative syntax generally fails in the same supplementary reading. This dictionary marks the analysis as provisional and has one constructed illustration. It lists the relative word as a part of this pattern.

Terms

Traditional grammar sometimes calls this a non-restrictive relative clause. CGEL: supplementary relative clause.

Examples

  • Jo visited Bath, which she had never seen before.

Watch for

  • A learner might read the which clause as helping to pick out which place is meant, when it adds information about a place already identified.
  • A learner might swap in that for which and expect the same added-information reading.

In class

Students write a sentence naming a place, then add a which clause with extra information about it. A partner explains what the clause adds and whether it helps identify the place.
