Teacher

Measure before ago

Useful for explaining how ago works with a measure phrase to count backwards from now.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is a PP made of a measure NP and ago. It locates an event or point by measuring backwards from the relevant deictic time, so four days ago paraphrases four days before now. Ago normally takes its measure before it. By contrast, temporal before takes a reference complement after it. Since Monday gives the start of an interval, whereas four days ago locates an event relative to the deictic time. This dictionary treats the analysis as provisional.

Terms

This dictionary treats the whole of four days ago as a PP.

Examples

  • The review arrived four days ago.
  • My bike broke two days ago.

Contrasts to teach

  • four days agoMeasures backwards from the deictic time.
  • since MondayGives the start of an interval.
  • before MondayTemporal before takes a reference complement after it.

Watch for

  • A learner might read ago as a word that comes first and takes a point of reference, like before.
  • A learner might think since Monday and four days ago do the same thing.

In class

Students put events on a timeline from today. For each, they write one sentence with a number and ago, and another with since or before and a named day.
