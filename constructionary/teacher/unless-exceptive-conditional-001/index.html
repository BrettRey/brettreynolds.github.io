Teacher

Exceptive Conditional Unless

Helps explain unless as marking the exception to the main claim.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is a prepositional phrase headed by unless plus a finite clause. It presents the condition as an exception to the main claim. In The door will stay locked unless Lee comes back, the door remains locked outside cases in which Lee comes back, and the sentence need not determine what happens if Lee does return. This dictionary marks its analysis as provisional and relates it to the if-conditional. Teach it as an exception marker with its own meaning, and compare it with if.

Terms

Unless is a preposition here.

Examples

  • The door will stay locked unless Lee comes back.
  • We'll eat outside unless it rains.

Contrasts to teach

  • The door will stay locked unless Lee comes back.Names the exception; the return case is left open.

Watch for

  • A learner might think the sentence says what happens when Lee does return, though this dictionary says it need not.
  • A learner might treat unless as a plain synonym of if not.

In class

Students write a rule for the classroom with unless, then swap and identify the exception in each other's rule.
