Resultative with a Nonselected Object

For advanced classes, resultatives where the object is not the verb's ordinary object.

How to explain it

The pattern is a VP with a verb, a noun phrase that is not the ordinary object of that verb, and a result predicate. It licenses an affected participant through the result predicate, including when the base verb normally takes no such object. In shouted the baby awake, the baby need not be an addressee, and the result requires an affected participant. Dropping awake removes that reading. This dictionary says this family goes beyond the reflexive-only subtype in the CGEL comparison, and records CGEL's narrower agentive intransitive pattern in a linked entry. The analysis is marked provisional.

Terms

Resultative is the traditional name. The noun phrase is sometimes called a nonselected or unselected object.

Examples

  • The neighbours shouted the baby awake.

Contrasts to teach

  • The neighbours shouted the baby awake.The baby is an affected participant; awake gives the result.
  • The neighbours shouted at the baby.An addressee reading is possible, with no change of state attributed to the baby.

Watch for

  • A learner might read shouted the baby awake as meaning the baby was spoken to, when the result word supplies the affected-participant reading.
  • A learner might think awake can be dropped without changing the meaning.

In class

Give students intransitive verbs such as laugh, sing and shout. In groups they try to add an object and a result phrase, then discuss what each object has become.
