Teacher

Deliberative what if

Helps explain what if as a way to raise a hypothetical and invite discussion of consequences.

Early sketch. The linguist entry has one example so far and its evidence isn’t written up yet. Use this page as a starting point, not a settled account.

How to explain it

The pattern is what if followed by a finite clause. It raises a hypothetical circumstance and invites consideration of its consequences. A response can discuss a plan for that circumstance. The string can stand alone without a stated matrix consequence, unlike a fully expressed ordinary conditional. This dictionary relates it to if-conditionals and to questions, classes it as pragmatic, and marks its analysis provisional. Teach it as a way of raising a scenario that can stand without a stated consequence.

Terms

Sometimes called a what-if question. This dictionary treats it as a deliberative use.

Examples

  • What if the last bus has already gone?
  • What if it snows tomorrow?

Contrasts to teach

  • What if the last bus has already gone?Stands alone; no consequence stated.
  • If the last bus has gone, we'll walk.Ordinary conditional with both parts.

Watch for

  • A learner might wait for a main clause after what if, when the string can stand alone.
  • A learner might answer with yes or no as to a plain question, when it invites discussion of the scenario.

In class

Students pose What if questions about a story's plot. Partners respond with a plan or consequence.
