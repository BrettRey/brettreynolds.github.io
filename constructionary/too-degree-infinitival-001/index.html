Too much for an action

Too plus a describing word and an action can say that something goes past the limit that action sets.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In The gap was too narrow for the crate to fit through, the word too doesn't just say the gap is very narrow. It says the gap is narrow past a certain point, and that point is set by what has to happen: the crate fitting through.

So the sentence says nothing general about how narrow the gap is. The same crate could count as large enough for other purposes. What matters is only whether it can fit through that gap.

The dictionary marks this account as provisional.

Examples

  • The gap was too narrow for the crate to fit through.
  • The box was too heavy to lift.
