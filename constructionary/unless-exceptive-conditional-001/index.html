Unless as an exception

A phrase starting with unless presents a condition as an exception to the main claim.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In The door will stay locked unless Lee comes back, the part with unless presents a condition as the exception. Outside the cases in which Lee comes back, the door remains locked.

The sentence doesn't need to say what happens if Lee does return. It only tells us what to expect in the ordinary case, and flags the exception.

The dictionary marks this account as provisional.

Examples

  • The door will stay locked unless Lee comes back.
  • We'll eat outside unless it rains.
