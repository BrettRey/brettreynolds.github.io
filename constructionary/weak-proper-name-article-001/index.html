Names that come with the

Some names include the word the as part of the name, as in the Thames.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

In They crossed the Thames, the word the isn't an extra. It belongs to the way this name is used in an ordinary sentence. The name and the article go together.

That differs from names that need nothing in front of them. The dictionary describes the article here as part of the ordinary naming pattern. A label or compound can leave it out in a suitable form, but arbitrarily swapping in a does not keep the main name use.

The dictionary marks this account as provisional.
