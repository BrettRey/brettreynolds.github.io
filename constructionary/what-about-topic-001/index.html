What about this idea?

What about, followed by a thing or an action, puts something forward for the other person to think about.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

What about asking Lee first? isn't really a request for information. It proposes an action, asking Lee, for the listener to consider.

The words after what about can name an action, as here, or a thing. With something like the spare key, the conversation supplies what the issue is. The speaker doesn't need to ask what the object is.

The dictionary marks this account as provisional.

Examples

  • What about asking Lee first?
  • What about the spare key?

Try it

Suggest something to a friend using What about. Does the friend answer with information or with a decision?
