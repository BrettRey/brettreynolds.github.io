What if something happened?

What if plus a clause raises a possible situation and invites talk about what would follow.

Early sketch. The full entry for this pattern has one example so far and its evidence isn’t written up yet, so treat this page as a starting point.

What if the last bus has already gone? doesn't ask for a fact. It raises a possibility and invites the listener to think about it.

A reply can discuss a plan for that situation, such as walking or calling a taxi. The string can stand alone without a stated result, unlike a fully expressed if sentence such as If the last bus has gone, we'll walk.

The dictionary marks this account as provisional.

Examples

  • What if the last bus has already gone?
  • What if it snows tomorrow?

Try it

Ask a friend What if with something that could happen on the way home. What do they say you should do?
