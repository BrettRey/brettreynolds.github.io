Source & notation

Function labels appear above category labels. Use N for nouns, including pronouns, and V for verbs, including auxiliaries. A phrase can contain one word. The top node has no function label because it has no parent.

Checking covers these four worked examples. A difference from the book’s tree is an invitation to inspect the analysis; it is not a general judgment about every possible tree.

Build the relationships

  1. Label words. Drag a word category onto its word. Or select the word, then click a category.
  2. Build a phrase. Turn on “Select a group” and select neighbouring branches. Choose a phrase category to group them. For a one-branch phrase, select just that branch.
  3. Work from the top. Clear the selection and choose a phrase category to add an empty node. Drag branches onto that node to attach them.
  4. Set functions. Select an attached branch and choose Head, Subj, Obj, Comp, Mod, or Det.
  5. Revise. Drag a whole branch to a phrase node. Without dragging, select it, choose “Move branch” in the tools, then select its new parent. The branch needs a function in that new relation.

Shift-click also adds to a selection. Use Tab and Enter/Space for the same controls without a pointer. Escape cancels a move or selection. Undo and redo are available with the buttons or ⌘/Ctrl Z and Shift Z. The canvas scrolls when the tree is wider than the screen.
