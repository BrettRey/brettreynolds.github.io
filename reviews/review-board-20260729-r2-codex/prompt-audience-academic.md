## Do this in order

1. **The assessment read.** What is this person's rank, affiliation, and field?

2. **The record.** What have they published, where, and is it any good? Compare

3. **The seniority signal.** Does this page read as an early-career researcher,

4. **Risk flags.** Anything here that would make you hesitate: overclaiming,

5. **Verdict.** For each role: would you invite them to review, and would you
   shortlist them? Say what the page did or failed to do in each case.
